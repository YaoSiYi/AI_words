# 《九鼎记》高层风格转化规则

> 状态：V1，基于全书跨阶段样本提炼  
> 用途：创作具有清晰升级、战斗因果和强连载推进感的原创武侠玄幻文本  
> 边界：不精确模仿作者，不使用原作专名、人物、世界规则、标志性措辞或情节组合。

## 一、目标读感

读者应当获得以下体验：

- 开场三段内知道人物在哪里、要做什么、什么东西妨碍他。
- 每一场冲突都能说清双方优势、限制和胜负条件。
- 每一次实力变化都有可见后果，不靠空泛形容词宣布。
- 每章至少改变一项状态：关系、实力、情报、地位、目标或危险。
- 主角变强的同时，始终有具体的人或地方值得他保护。
- 文字顺滑直给，阅读速度快，但重要动作不含糊。

## 二、叙述配置

### 视角

- 默认第三人称近距跟随当前核心人物。
- 一场戏只保留一个主要感知中心。
- 可在场景分隔后切换敌手、高层或围观者，用于补威胁和社会反馈。
- 不为炫耀信息频繁跳头。

### 叙述距离

- 行动和战斗时贴近：写当下所见、判断和选择。
- 交代势力规则时稍拉远：只补理解当前局势所必需的信息。
- 情感场先贴动作，后点明情绪。

### 信息释放

按“遇到再解释”处理世界观：

1. 先出现具体人、物或制度。
2. 说明它与当前目标的关系。
3. 给出一个比较标尺。
4. 保留一项暂时不知道的信息。

禁止连续三段百科说明后人物才开始行动。

## 三、句式与分段

- 常态句以 8—18 个汉字为主。
- 动作落点可以更短，但不要连续十段都是碎句。
- 连续动作可用一个较长句写完整因果，不要每个动作都另起一段。
- 单段以 20—60 个汉字为常态。
- 对话段可占全章约三至四成，必须同时推进关系、信息或冲突。
- 拟声词只在真正改变动作节奏时使用。
- 关键结果可延后一段揭示，但一场战斗不反复使用同一悬停手法。

推荐节奏：

`具体动作 → 即时变化 → 人物判断 → 下一动作`

不推荐节奏：

`形容很强 → 再说非常强 → 围观者说太强 → 旁白总结果然很强`

## 四、力量与爽点写法

每项重要能力至少用两种证据证明：

1. **物理证据**：物体、距离、伤势、速度、地形发生变化。
2. **专业证据**：懂行人物判断其难度或代价。
3. **制度证据**：榜单、职位、谈判态度、势力决策发生变化。

三种证据不必全部重复。优先让最有说服力的一项承担主要证明。

写数字时必须回答“这个数字对现场意味着什么”。数字不能只用于越堆越大。

爽点完整结构：

`旧排序建立 → 对方按旧排序行事 → 主角用事实打破排序 → 权威重新定价 → 主角获得新行动空间`

## 五、战斗规则

### 开打前

用一至两段交代：

- 双方距离和位置。
- 各自最明显的武器或优势。
- 主角不能承受的失败代价。
- 当前最优先解决的威胁。

### 交手中

至少出现三次局势变化：

1. 第一次试探，确认对方并非表面水平。
2. 一次受阻或失误，暴露真实限制。
3. 利用地形、信息差、心理或技法改变条件。
4. 决定胜负的招式最后出现。

每一个关键动作都要能回答：

- 为什么此刻使用？
- 为什么对手没能轻易避开？
- 使用后付出什么？
- 它如何改变下一步？

### 收尾

- 先写结果，再写解释。
- 用一个物理细节固定战果。
- 用一个人物反应说明地位变化。
- 最后给出下一项未解决危险。

## 六、人物声音

### 核心行动者

- 句子短，少做口头炫耀。
- 先判断条件，再下决定。
- 不轻易承诺；一旦承诺，后续行动必须兑现。
- 对敌时冷静直接，对家人与弟子保留朴素关心。

### 经验型长辈或首领

- 说话常从后果、利益和传承出发。
- 不只负责夸主角，要有自己的取舍。
- 能指出主角当前方案的代价。

### 对手

- 必须有一个合理目标和一个认知盲区。
- 威胁应来自资源、经验、位置或信息，不只来自傲慢。
- 不用好色、蠢笨、嚣张作为唯一人格。

### 普通人和围观者

- 只保留最有代表性的两三个反应。
- 反应要与身份有关：军士看纪律，商人看代价，武者看技法，家人看安危。
- 不要让所有人轮流说“太强了”。

## 七、情绪规则

情绪优先通过以下东西出现：

- 手上正在做的小事突然停了。
- 熟悉物件引出记忆。
- 人物改口、沉默或改变站位。
- 原本舍不得的东西被放弃。
- 人物在两个都重要的目标之间选择。

允许在动作之后用一句话点明情绪，不要每个动作后都解释心理。

情感主轴建议采用：

`能力增长 ↔ 保护对象扩大 ↔ 个人自由受到更大约束`

这样升级既带来快感，也带来新的责任。

## 八、章节模板

### 常规推进章

1. 具体场景开门。
2. 人物要完成一件明确小事。
3. 新阻力出现。
4. 当前规则或强弱尺度被说明。
5. 人物行动并获得局部结果。
6. 结果引出更大的问题。

### 战斗章

1. 空间与胜负条件。
2. 第一次交锋。
3. 对手亮出真实手段。
4. 主角修正判断。
5. 关键反制。
6. 战果与代价。
7. 新敌情或后续决定。

### 情感章

1. 日常动作。
2. 关系中的旧习惯。
3. 危机或分别逼近。
4. 记忆与当前动作互相照亮。
5. 人物做选择，不用长篇表白替代。
6. 选择改变下一步剧情。

## 九、禁用与限用

### 禁用

- 原作人物名、组织名、境界名、招式名、地理名和标志性道具。
- 复刻原作具体战斗、危机、感情确认或身份反转。
- 把“模仿某作者”写进生成提示。
- 只换专名、不换场景因果的改写。
- 用女性外貌排序代替人物塑造。

### 限用

以下词不是绝对禁用，但同章应控制频次：

- 竟然、根本、立即、瞬间、猛地、顿时、陡然。
- 脸色一变、倒吸一口凉气、难以置信、怎么可能。
- 仿佛猛虎、宛如闪电、好似高山、目光如刀。
- 心中暗道、心底明白、显然、毕竟。

连续两次使用同类反应词，第二次应改成具体动作或现场后果。

## 十、写后验收

- [ ] 三段内是否出现具体目标和阻力？
- [ ] 本章改变了哪一项状态？
- [ ] 强弱判断是否有物理证据？
- [ ] 战斗是否至少有三次局势变化？
- [ ] 关键招式是否解决了前面提出的具体问题？
- [ ] 是否有一个可触摸的生活细节维系人物？
- [ ] 对话是否区分了身份与关系？
- [ ] 是否重复解释了同一结论？
- [ ] 是否连续堆叠震惊、脸色变化和通用比喻？
- [ ] 章末钩子是否由本章结果自然生长？
- [ ] 是否完全避开原作专名、句子和情节组合？

## 十一、可直接使用的原创写作提示

以第三人称近距视角写一章原创成长型武侠玄幻正文。语言清楚直接，短句与中等长度动作句交替，段落适合快速阅读。开场三段内交代人物的具体目标、现场阻力和失败代价。力量体系必须通过物理后果、懂行人物判断或制度反应来证明，不能只用形容词宣布。战斗围绕一个明确局势难题推进，至少经历试探、受阻、改写条件、关键反制四步。世界设定遇到时再解释。情绪先通过小动作、物件和选择表现，再有限度点明。结尾必须改变一项状态并引出下一问题。不得使用任何现有作品的专名、标志性措辞、人物关系或情节组合。
