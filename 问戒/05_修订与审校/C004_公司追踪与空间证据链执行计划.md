> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把已批准的维恩职务、跨境盲拍追踪链和后姚村空间证据回传链写入《问戒》正史，并关闭连续性问题 C004。

**Architecture:** 先更新势力与人物文件，确定谁能知道和调用什么；再更新历史与第一卷，闭合盲拍到姚逸的追踪链；随后更新第三卷、时间线和冲突链，闭合空间硬证据回传；最后同步确认快照与审校记录，并用关键词矩阵检查是否提前泄露空间功能。

**Tech Stack:** Markdown 小说圣经、角色库、卷纲、时间线、伏笔表、状态快照与连续性审校记录。

**Status:** 已执行并通过C004独立连续性复核。
