# 《问戒》戒指容量与库存账本

> 本文件是戒指物理空间容量、扩容时间和关键物品占用量的唯一详细账本。其他文件只保留阶段摘要；发生差异时，以本账本和 `规则系统.md` 为准。

## 一、阶段定义

初始 1 立方米计为第一阶段。每次扩容容量翻倍：

| 阶段 | 容量 |
| ---: | ---: |
| 第一阶段 | 1 立方米 |
| 第二阶段 | 2 立方米 |
| 第三阶段 | 4 立方米 |
| 第四阶段 | 8 立方米 |
| 第五阶段 | 16 立方米 |
| 第六阶段 | 32 立方米 |
| 第七阶段 | 64 立方米 |
| 第八阶段 | 128 立方米 |
| 第九阶段 | 256 立方米 |
| 第十阶段 | 512 立方米 |
| 第十一阶段 | 1024 立方米 |

第十一阶段以后继续翻倍，理论上没有固定上限。

## 二、常规扩容算法

设第一次从 1 立方米扩至 2 立方米所需能量为基准单位 `E`：

| 扩容 | 所需新增能量 |
| --- | ---: |
| 1 → 2 | E |
| 2 → 4 | 4E |
| 4 → 8 | 16E |
| 8 → 16 | 64E |
| 后续 | 每级为前一级所需能量的 4 倍 |

- 第一次扩容由姚逸旧藏中的特殊含能玉石一次性提供 `E`。
- 太极玉在未引爆时不能被戒指直接吞噬，戒指只能吸收其表层稳定泄漏。
- 地球阶段的安全吸收速度约为每 45 天获得 `4E`。
- 每次升级的结构调整与稳定时间已经计入阶段日期。
- 按常规速度，从 8 立方米扩到 16 立方米还需约 720 天，因此在地球篇终战前无法完成。

## 四、太极玉引爆后的跨级扩容

- 地球篇终章，太极玉逆相引爆。
- 外向能量形成毁灭性爆发；向内坍缩的核心能量被戒指根层捕获。
- 这次输入不再经过地球阶段的表层吸收通道，而是直接冲入戒指空间骨架。
- 戒指在空间乱流中连续完成：

  `8 → 16 → 32 → 64 → 128 → 256 → 512 立方米`

- 连续跨级结束后，戒指稳定在第十阶段、512 立方米。
- 扩容完成早于姚逸左臂被空间剪切斩断；因此戒指与姚逸分离时，内部空间已经是 512 立方米。
- 姚逸当时忙于在空间乱流中求生，不知道容量已经变化。
- 小一处于融合与休眠状态，也没有即时向姚逸报告。

### 极限扩容中的根层变化

- `8→16→32`：空间骨架超负荷重构。
- `32→64→128`：隔绝小一的根层分区出现裂缝。
- `128→256`：隐藏的造物主回收接口被强制唤醒。
- `256→512`：后门尝试执行带有辰龙主印的身份握手。
- 小一截获并隔离握手副本，在地球坐标回传前主动切断连接；她无权删除后门。
- 512 立方米稳定时，戒指光脑底库完成物理修复，但内容仍需后续分层解密。

## 五、宇宙背景能量摄取接口

太极玉核心能量不仅完成跨级扩容，还永久拓宽戒指的能量通道，形成“宇宙背景能量摄取接口”。

### 光能通道

可吸收：

- 恒星辐射；
- 宇宙背景光子；
- 高能粒子流；
- 其他可被戒指转化的电磁与辐射能量。

### 暗质通道

可耦合：

- 暗物质背景；
- 真空能量梯度；
- 星盟统称的暗质背景能量。

“光暗能量物质”是人物口语统称，正式设定不把暗物质与暗能量视为完全相同的现实物理概念。

### 能量分配优先级

1. 维持紧急见证槽及石磊连续意识封存。
2. 维持戒指空间结构与安全锁。
3. 维持小一的智能核心、运算与苏醒。
4. 补充虚拟层、扫描、通信和常规功能消耗。
5. 只有剩余能量才进入下一阶段扩容储备。

### 石磊封存供能交接

- 2067 年 12 月 27 日 20:55:00 锁定见证槽时，戒指先从现有储能中划出不可挪用的最低维持份额。
- 太极玉引爆前，该份额由戒指原有储能和太极玉表层稳定泄漏共同维持。
- 2068 年 3 月太极玉引爆并形成宇宙背景能量摄取接口后，长期最低供能自动切换至背景能量接口。
- 供能切换由见证槽底层保全协议完成，不要求小一清醒，也不要求姚逸佩戴戒指。
- 若输入降低，系统按“扩容 → 高耗模拟 → 联网与扫描 → 小一主动运算”的顺序停用功能，不得挪用见证槽份额。
- 能源只能维持封存质量，不能增加 94,694,400 秒期限。

### 限制

- 宇宙背景能量吸收速度高于地球阶段的太极玉表层泄漏，但仍受戒指阶段、环境强度和结构承载能力限制。
- 背景能量可以维持小一和推动长期扩容，不能无损、瞬时转化为攻击光束或无限战斗能源。
- 第十阶段以后仍遵守“容量翻倍、所需扩容能量约为前一级 4 倍”的规则。
- 在贫能区、强干扰区或特殊封锁场中，吸收效率会显著下降。

## 六、容量计算规则

- 容量按物品稳定存放时的外部占用体积计算，不按物品质量折算。
- 不规则物品按安全收纳后的最小外包络体积计算。
- 休眠仓中的石磊已经位于仓体内部，不重复计算人体体积。
- 物品一旦释放到现实空间，真实质量、惯性和对地面承载力的要求立即恢复。
- 小一在占用达到总容量 85% 时发出安全警告；85% 不是强制上限，名义容量仍可全部使用。

## 七、关键库存核算

太极玉体积：

`π × 0.495² × 0.99 ≈ 0.762 立方米`

太极玉质量固定为 9.9 吨。2067 年 9 月安装九节点双环相位夹具后，组合体外包尺寸约为直径 1.04 米、高 1.03 米，按安全外包络占用约 0.88 立方米。

`2.15 米 × 0.82 米 × 0.72 米 ≈ 1.27 立方米`

## 八、物品状态铁律

- 太极玉在 2067 年 9 月安装夹具前占用约 0.762 立方米；安装后与夹具作为一个整体占用约 0.88 立方米。
- 太极玉与夹具组合体质量仍以 9.9 吨太极玉为主，只能由戒指直接接触收纳与释放。
- 石磊封存后，休眠仓作为一个整体占用约 1.27 立方米。
- 太极玉引爆后实体不再作为库存存在，其向内核心转化为戒指扩容、实体种子和宇宙背景能量接口。
- 戒指扩到 512 立方米不会自动把外界垃圾或爆炸碎片收入空间。
- 戒指与姚逸失散时，石磊、证据和原有装备仍保留在空间中。
