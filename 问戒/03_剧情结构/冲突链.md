# 《问戒》冲突链

## 一、地球篇主冲突链

无名死者带走资料  
→ 戒指随盲包落入姚逸手中  
→ 第二章血迹激活戒指，小一苏醒  
→ 姚逸测试 1 立方米空间并发现访客日志与根层空白  
→ 小一扫描旧藏，姚逸合法变现并归还失窃物  
→ 姚逸为合法变现伴随遗物提交来源核验  
→ 包装微标、批次号和材料指纹触发杰盘沟监控  
→ 读者先知道公司只把戒指视为主密钥载体  
→ 姚逸保护余声并重启旧日伦理承诺  
→ 公司把范围缩至姚逸  
→ 姚逸误判杰盘沟知道空间功能  
→ 回收组误判姚逸知道归潮计划  
→ 第三十章双方在错误前提上完成第一次正面碰撞  
→ 双方防范行动相互验证错误判断  
→ 多派系行动互相拆台，形成误会喜剧  
→ 回收组三人最终比对黑戒指外形，仍未取得空间证据  
→ 后姚村取证蜂在通讯恢复后执行死亡回传  
→ 姚逸选择先救石磊，放弃清除观察节点  
→ 石磊和休眠仓在三源连续记录中凭空消失  
→ 技术续生派确认空间能力  
→ 罗萨从异常入库审计发现维恩越权  
→ 追回机密升级为控制戒指  
→ 4 月偶发逆相与 9 月表层受控实验留下唯一安全数据  
→ 姚逸把紧急泄能协议和夹具作为石磊见证槽的保护预案随身携带  
→ 姚逸被逼入杰盘沟绝境  
→ 姚逸在中轴调谐井越权解除三道安全锁，9 秒核心逆相不可逆  
→ 轴向护场错开第一波能量，向内核心撕开空间裂口  
→ 戒指连续扩至 512 立方米，造物主回收接口提前暴露  
→ 小一截断地址回传后过载休眠，地球仍未被定位。

## 二、姚逸内在冲突链

早年服从程序删除觉醒意识  
→ 形成“不随意删除自我意识生命”的红线  
→ 得到以自己为核心的小一  
→ 习惯性把她当作高智能功能  
→ 小一形成独立偏好并拒绝  
→ 姚逸面临“主人权限是否可以覆盖她”  
→ 姚逸销毁重置权  
→ 伦理钥匙成立  
→ 终局能够反制创造者的所有权逻辑。

## 三、三兄弟冲突链

姚逸习惯独自扛事  
→ 单人进入湿地并失联十天  
→ 石磊、刘振建立强制报备规则  
→ 三人共同参与太极玉支线  
→ 杰盘沟围捕升级  
→ 技术续生派趁姚逸在汉城，袭击后姚村并试图绑架姚家长辈  
→ 第二层石磊、刘振将八名死士全部击杀  
→ 石磊胸腹中弹、临床死亡，刘振启动休眠仓  
→ 刘振在电话中情绪决堤，说出“二哥没了”  
→ 姚逸短暂失神后强制冷静，九十秒内完成伤情确认与方案判断  
→ 小一并行计算二百公里近直线应急路线与十八分钟意识锚窗口  
→ 姚逸在倒计时中不断要求“再快一点”，从音速附近逐段推至一点六倍音速  
→ 《九折步》在一点六倍音速节点进入大圆满，姚逸继续突破至接近一点八五倍音速  
→ 姚逸约五分四十秒返乡  
→ 姚逸来不及救活石磊，只能完成紧急见证并背负三年承诺  
→ 刘振主动留守地球  
→ 兄弟关系从“永远一起上”转为各自承担不同战场。

## 四、能力冲突链

姚逸获得十二层基础功法  
→ 地球境界快速提升  
→ 缺少武技与实战  
→ 湿地洞窟只补足有限针诀、步法和兵器  
→ 第三层姚逸以严重身体损伤为代价完成一次二百公里超音速过载，并把《九折步》推至大圆满  
→ 过载无法用于复杂战斗，反而证明速度、实战和救人不是同一件事  
→ 第四层仍无法碾压成熟大宗师  
→ 戒指与左臂失散  
→ 姚逸在废籍星必须证明自身成长不是外挂依赖  
→ 最终把无人重视的基础功法练至十二层。

## 五、文明冲突链

杰盘沟把复制人格视作产品与延续服务  
→ 姚逸面对“复制是否等于本人”  
→ 星盟把弱族与无身份者当作资源  
→ 卯兔族因揭露事实被整体奴役  
→ 无边海帝国把智慧体、持有者与文明遗产纳入所有权  
→ 光脑底库以“制造者记录”定义历史，却可能夹带伪造与夺舍诱导  
→ 未央必须用另外两枚纯玉戒指与帝国遗址交叉验证自身来源  
→ 创造者试图收回未央并夺舍姚逸  
→ 姚逸以见证而非占有完成终局选择。
