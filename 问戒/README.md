# 《问戒》项目导航

## 正式创作依据

1. 项目边界：`00_项目总纲/项目说明.md`
2. 创作目标：`00_项目总纲/创作目标.md`
3. 世界与能力规则：`01_设定资料库/`
   - 戒指容量与关键库存：`01_设定资料库/戒指容量与库存账本.md`
   - 意识锚、极速返乡与封存时钟：`01_设定资料库/意识锚与紧急见证时间账本.md`
4. 人物资料：`02_角色资料库/`
5. 全书与地球篇结构：`03_剧情结构/`
6. 文风和审校规则：`05_修订与审校/`
7. 最高优先级确认快照：`06_状态快照/已确认设定.md`
8. 当前工作位置：`06_状态快照/当前上下文.md`

## 优先级

用户最新明确指令  
> 已确认设定  
> 已写正文  
> 事实快照  
> 卷纲 / 章纲  
> 待确认事项  
> 参考资料

## 参考隔离

`07_参考资料/` 中的《戒指传奇》拆解不属于《问戒》正史。正式创作不得从参考文件直接提取可识别角色、情节组合或语言表达。
