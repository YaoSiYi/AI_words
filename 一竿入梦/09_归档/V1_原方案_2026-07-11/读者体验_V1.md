# 读者体验

## 核心体验

- 体验关键词：夜钓、空军、嘴硬、入梦、怪鱼、系统限制、万水竿、全球水域、钓鱼判断、生态敬畏。
- 情绪曲线：现实尴尬开局 -> 入梦惊异 -> 关卡翻车 -> 系统有限提示 -> 主角靠经验调整 -> 高燃上鱼或遗憾脱钩 -> 下一关悬念。
- 爽点 / 痛点 / 悬念点：爽点是靠判断破局；痛点是空军和误判；悬念点是系统目的、万水竿来历和梦境痕迹。

## 阅读节奏

- 开篇节奏：快，第一章就要出现夜钓空军、嘴硬喜剧和异常浮漂。
- 中段节奏：一关一难题，穿插现实喜剧线与钓鱼知识点，避免连续设定说明。
- 后段节奏：扩大系统谜团和现实影响，推动主角从“要钓上来”转向“要理解水域规则”。

## 注意事项

- 不希望出现的表达方式：万能系统、空泛热血、硬塞科普、连续口头禅堆砌。
- 不希望出现的剧情处理：每关都靠系统直接答案获胜；怪鱼只作为战利品；现实线完全断开；主角永远不承认自己错。
