# 项目通用视觉素材

这里存放《一竿入梦》跨档案复用的最终参考图。

```text
characters/laoyao/selected_laoyao_reference.png
characters/xiaohuang/selected_xiaohuang_reference.png
props/wanshuigan/selected_wanshuigan_reference.png
color/archive_001_palette_locked.png
```

只有通过一致性审核的图片才能使用 `selected_` 前缀。候选图可以保留，但不要让多个候选图同时作为默认参考图。

档案专属场景、异常证据物和特殊状态图不要放在这里，应放入对应的 `archive_XXX/` 目录。
