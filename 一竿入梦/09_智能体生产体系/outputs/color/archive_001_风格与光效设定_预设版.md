# 档案001 风格与光效设定

版本：V2.0预设版  
适用范围：角色设定图、道具图、场景图、水下视角、Seedance关键镜头和封面。  
状态：基于当前参考图与剧本建立，待四个关键镜头生成后校准。

## 一、总风格设定

```text
真实民间钓鱼伪纪录片，低照度、低饱和、克制写实、轻微手持摄影感。画面像摄制组在真实夜钓现场记录异常证据，不像电影预告片、游戏过场或玄幻海报。优先表现真实材质、人物动作、鱼线受力、设备噪点、水面反光和偶然记录感。
```

## 二、风格层级

### 影像媒介

- 民间纪录片、现场调查、低预算但可信的摄制质感。
- 手持摄影可以有轻微呼吸感和寻找焦点，但不能晃到看不清动作。
- 允许轻微高ISO颗粒、压缩噪点和水下设备噪点。
- 不使用统一的商业广告锐度，不使用过度干净的棚拍画面。

### 构图与镜头

- 每个镜头只表达一个主要动作或一项证据。
- 人物动作优先于炫技运镜，镜头运动必须有现场动机。
- 关键证据采用中近景、特写或微距，不使用夸张英雄低角度。
- 异常尽量出现在画面边缘、反光、设备回放或水面细节中。

### 材质

- 湖面：黑、湿、低反光但保留真实层次。
- 岸边：湿泥、旧木、暗草、石墨灰钓具。
- 人物：真实皮肤、旧布料、户外使用痕迹，不要塑料皮肤。
- 万水竿：旧台钓手竿、磨损握把、浅刻篆体“水”字、极淡蓝色水纹。
- 异常鳞片：湿润、青黑、细密磨痕，作为证据而不是战利品。

## 三、光效设定

### 白天环境基准图

- 阴天或柔和自然日光。
- 光线均匀、方向不夸张，表现真实湖岸地形。
- 不使用金色日落、强烈镜头光晕和商业风景片光线。

### 夜间无声湖

- 主光源只能是现场夜钓灯、头灯或摄制设备的弱补光。
- 夜钓灯为冷白色，照亮人物手部、钓具、鱼护和局部岸边。
- 背景保持黑暗，但必须保留树影、湖岸和水面的层次。
- 老姚脸部不能过曝，眼睛不能被强光打成网红写真效果。
- 不凭空增加轮廓光、霓虹光、舞台光或强烈蓝光。

### 万水竿反应

- 淡蓝色水纹是竿身材质变化，不是主动发光。
- 水纹只能局部、低亮度、低对比出现。
- 水纹不投射到人物脸上，不产生光束，不照亮环境。
- 暗红色只属于竿梢头，是实体材质色，不产生红光。

### 异常鳞片证据

- 使用冷白夜钓灯或小型证据拍摄灯的局部侧光。
- 鳞片表面可以有湿润冷反光，但不能发光。
- 背景压暗，微距主体清楚，保持证据照片而非战利品展示。
- 不使用血红、金色、彩虹反光和怪兽电影式高光。

### 水下摄像机

- 使用水下设备自身的微弱冷色补光或浑浊水体中的自然残光。
- 画面青黑、灰绿、低能见度，悬浮颗粒和设备噪点真实可见。
- 暗影不被补光照亮，只表现遮光变化和水体扰动。
- 不使用清澈海水的阳光光束，不使用蓝色水族馆光效。

## 四、异常视觉控制

```text
异常出现顺序：环境声归零 → 浮漂同时静止 → 小黄拒绝靠近 → 水下边缘暗影 → 万水竿浅蓝水纹 → 鱼线横向受力 → 异常鳞片证据。
```

- 每次只增加一个异常层级，不提前展示最终答案。
- 淡蓝色水纹是全档案唯一异常记忆色。
- 暗影永远不完整露出，不出现清晰眼睛、头部或怪物正脸。
- 任何异常都必须像摄像机偶然记录到的证据，而不是特效展示。

## 五、统一禁用项

```text
电影预告片式过度戏剧化，商业广告棚拍，高光磨皮，橙色网红滤镜，青橙大片预设，霓虹蓝紫，金色神光，强烈蓝色轮廓光，魔法光柱，闪电特效，游戏HUD，系统面板，玄幻符文，英雄战斗姿态，怪兽正脸，血腥，战利品展示，塑料皮肤，过度锐化，纯黑无层次，脸部过曝，水下阳光光束，清澈热带海水
```

## 六、生成前检查

- 是否仍然像真实民间摄制组拍摄的现场？
- 光源是否能在场景中找到现实来源？
- 蓝色是否只作为克制水纹，而不是魔法光？
- 暗红色是否只存在于台钓竿梢头？
- 人物、道具和鳞片是否保留真实材质？
- 异常是否只给证据，没有直接给答案？

## 七、下游调用规则

- 角色设定图：调用总风格、人物材质和对应服装色彩规则。
- 场景设定图：调用白天或夜间对应光效，不混用。
- 水下视角：调用水下摄像机光效，不调用夜钓灯直接照明。
- Seedance镜头：每个镜头只允许一个主要光效变化。
- 质量审核：发现任意禁用项时，先回滚提示词中的光效和风格词，再重新生成。
