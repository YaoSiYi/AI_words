# 档案001 外部接入试跑总审核

审核日期：2026-07-11  
审核对象：档案001《无声湖停口事件》外部 AI 短片 Agent 接入试跑包  
审核范围：留存、短剧脚本、Seedance分镜、提示词、视觉一致性、剪辑节奏、发布包装

## 一、总体判断

本次试跑可用。

外部 `AI短片` 能力已经成功转译进《一竿入梦》V2.0，没有回到 V1 的系统面板闯关逻辑。当前版本最适合作为档案001的首条试播包基础。

强项：

- 首屏异常明确：整片湖突然无声。
- 人物有辨识度：老姚嘴硬，小黄本能预警。
- 钓鱼知识有承接：有鱼星没口，先判断鱼层。
- 世界观线索克制：万水竿水纹、异常鳞片、7秒回放。
- Seedance镜头拆分合理：每镜一个主动作，便于生成。

主要风险：

- 钓鱼知识仍需根据具体水域、季节、目标鱼进一步核验。
- 鱼线横向拖动镜头是生成难点，必须重点返修。
- 如果暗影露出太多，会破坏伪纪录片未知感。

## 二、专业审核

通过，但需保留“现场判断”口吻。

可保留：

- 有鱼星没口时，不应只盯饵料和调漂。
- 鱼层、水温、溶氧、小鱼活动、漂相变化可以作为综合判断依据。
- 改试中上层作为剧情里的二次判断是合理方向。

需避免：

- 不要写成“有鱼星没口一定是鱼层问题”。
- 不要让观众误以为异常鱼情是真实垂钓建议。
- 不要把“鱼线横着走”解释成单一现实原因，保持档案悬疑。

建议字幕：

```text
短剧演绎，不构成真实垂钓建议。
```

## 三、故事与连续性审核

通过。

当前因果链成立：

```text
连续空军
  -> 有鱼星没口
  -> 老姚误判饵料/调漂
  -> 小黄和收音提供异常证据
  -> 水下暗影打破常规解释
  -> 万水竿有限提示
  -> 老姚改试中上层
  -> 鱼线横向拖动
  -> 获得异常鳞片
  -> 引出深潭切线事件
```

未发现明显世界观冲突。老莽头只出现一次提示，符合 V2.0 限制。

## 四、留存审核

通过。

节点检查：

- 0-3秒：有强异常画面和声音钩子。
- 8-15秒：小黄提供第二证据，避免单纯钓鱼教学。
- 31-39秒：水下暗影形成“答案只对一半”。
- 49-70秒：鱼线横走兑现主要爽点。
- 70-80秒：异常鳞片 + 7秒水纹形成复播理由。

建议首发优先使用 A 组发布版本：

```text
标题：这一秒，整片湖没声了
封面：整片湖没声了
```

原因：首条内容要先建立“伪纪录片异常证据”心智，再用后续切片补钓鱼知识。

## 五、Seedance / 视觉审核

基本通过。

高风险镜头：

1. A001-008 鱼线横向拖动。
2. A001-010 鳞片 + 7秒水纹回放。
3. A001-006 水下暗影。

返修优先级：

- 如果 A001-008 鱼线断裂或方向不清，必须重做。
- 如果 A001-006 暗影太像完整怪兽，必须改成边缘一帧。
- 如果 A001-010 鳞片变血腥或奖杯化，必须改成证据微距。

建议先生成定帧参考：

- 老姚定妆。
- 小黄定妆。
- 万水竿特写。
- 无声湖场景。
- 异常鳞片。

通过。

当前未出现：

- 非法捕捞鼓励。
- 真实公共安全事件伪装。
- 装备绝对化承诺。

发布前必须保留标识：

```text
AI创意短剧 / 怪鱼探索故事 / 短剧演绎，不构成真实垂钓建议。
```

当前只保留“浮漂灵敏度实验接口”，未强行带货。若后续植入，应遵守：

- 不承诺必上鱼。
- 不让商品替代万水竿和老姚判断。
