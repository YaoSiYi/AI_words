# 档案001《无声湖停口事件》留存诊断

版本：外部 AI 短片 Agent 接入试跑版  
参考能力：audience-retention-psychology  
目标平台：抖音  
建议时长：75-90秒

## 观众预期心理判断

观众点进来不是为了听完整钓鱼科普，而是想立刻确认三件事：

1. 这片水到底哪里不对。
2. 老姚是不是技术不行，还是水下真有东西。
3. 摄像机拍到的证据能不能证明异常。

当前最强心理机制是“好奇缺口 + 专业参与 + 未完成效应”。开头要让观众知道：湖不是普通安静，而是“连声音都像被关掉了”；中段让观众跟老姚一起误判；结尾用异常鳞片和7秒水纹促使复播。

## 3秒Hook强度

评分：4.5 / 5

现有优势：

- “六支浮漂同时静止 + 水声突然消失”具备强异常画面。
- 摄制组低声发问有伪纪录片真实感。
- 开场不依赖讲解，先给证据。

建议强化：

- 0-3秒字幕不要写“无声湖停口事件”，而写更像证据的短句：`这一秒，整片湖没声了。`
- 第一镜不必解释鱼情，先让观众感到“现场声音被抽空”。

## 15秒留存点

当前风险：6-13秒信息略多，鱼星、漂相、小黄、收音波形同时出现，观众可能不知道重点。

建议重排：

```text
0-3秒：湖突然无声。
3-8秒：老姚空军嘴硬，建立人物。
8-15秒：小黄拒绝靠近水边，证明不是只有设备异常。
```

15秒前必须形成一个明确问题：

> 有鱼星、有漂、有老钓手，为什么整片湖都不开口？

## 30秒掉点风险

主要风险：

- 换饵、调漂如果拍得太正常，会像普通钓鱼教学。
- 老姚解释太多，会削弱异常压迫。

修正策略：

- 20-30秒必须让“第一次判断失败”可视化：调漂后漂仍然像被按住，水下摄像机边缘闪过暗影。
- 台词要短，不讲课。让老姚说一句判断，画面马上打脸。

推荐台词：

```text
老姚：不是饵的问题，就是漂调钝了。
摄制组：那这帧阴影呢？
老姚：别拿噪点吓唬人。
```

## 情绪曲线

```text
异常惊疑
  -> 老姚嘴硬缓冲
  -> 专业判断参与
  -> 判断失败压迫
  -> 万水竿低频提示
  -> 线被横拖的惊险
  -> 异常鳞片证据回报
  -> 7秒水纹复播钩子
```

## 评论触发点

表层专业评论：

- 有鱼星没口，你会先改钓层、换饵，还是挪钓位？
- 如果漂不动但鱼线横着走，你会继续控，还是立刻卸力？

深层世界观评论：

- 43秒鱼线不是往外跑，是横着拉镜头，这像鱼吗？
- 小黄不靠近水边，是闻到了鱼，还是闻到了别的东西？

## 转发/收藏触发点

收藏点：

```text
有鱼星没口，先判断鱼层，再考虑换饵和调漂。
```

转发点：

- 钓友会转给钓友争论“这种鱼情到底先改哪里”。
- 泛娱乐观众会转发“摄像机拍到了人没看见的东西”。

## A/B开头方案

### A. 悬念抛钩型

```text
画面：六支浮漂同时静止，环境声归零。
字幕：这一秒，整片湖没声了。
旁白：我们本来只想拍老姚空军。
```

适合：主推版，最符合伪纪录片调性。

### B. 身份反差型

```text
画面：老姚举空鱼护嘴硬。
老姚：有鱼星没口，不叫空军，叫鱼不配合。
下一镜：小黄突然退后，收音断掉。
```

适合：突出人物喜剧和钓鱼人代入。

### C. 证据回放型

```text
画面：钩尖挂着异常鳞片。
旁白：这枚鳞片，不是我们当天第一个证据。
回切7秒水纹。
```

适合：做复播/二次切片。

## 修改建议

1. 时长从60秒扩到75-90秒，给“第一次误判”和“二次专业修正”留足空间。
2. 0-3秒必须先给异常，不要先报标题。
3. 15秒前让小黄成为第二证据源。
4. 30秒处必须出现“答案只对一半”：饵料/调漂不是主因，鱼层和异常水流才是关键。
5. 结尾不要只说下一集，必须给可复播证据：7秒水纹和异常鳞片磨痕。
