# 《一竿入梦》V2.1 守水者框架设计规范

设计日期：2026-07-15  
设计状态：已由用户确认，自2026-07-15起作为V2.1上位设计依据  
结构增补：2026-07-17确认三层世界模型与“70现水 + 20回声 + 10汇流”百档案结构  
适用范围：全书大纲、十卷卷纲、百档案、小说正文、短视频脚本、Seedance 分镜、账号运营与合规审核

## 一、优化目标

V2.1 保留 V2.0 的怪鱼调查、伪纪录片、真实钓技、万水竿和老莽头，同时补上清晰的社会痛点、人物选择与账号价值观。早期六档案仅作为第一卷候选资产，不再作为完整季结构；全书正式采用10卷×10档案。

对外一句话定位：

> 一个懂钓鱼的异常水域调查员，用真实钓技追查怪鱼，也追查水域为何失去生命。

账号内容承诺：

> 钓的是答案，不是战利品。

第一季人物成长终点：

> 老姚从“证明自己不是空军”，成长为懂得什么时候下竿、什么时候收竿、什么时候放手、什么时候上报的守水人。

核心角色表达：

> 能钓上来是本事，知道什么时候放手是规矩。

## 二、设计决策

### 采用方案：选择驱动型生态叙事

每个档案都必须让老姚面对一次与钓获、流量、装备、证据或安全有关的真实选择。生态价值通过他的行动和代价成立，不依赖片尾说教。

示例：

- 为减少鱼体伤害，剪掉主线并放弃鱼获。
- 为保护疑似珍稀种群，不公开水域坐标并放弃流量。
- 为救助被废弃渔具缠绕的生物，停止追逐异常目标。
- 发现疑似违法捕捞证据后，保留现场信息、撤离并联系主管部门，而不是私自对抗。

### 不采用方案一：口号附加型

不把“保护水资源”只做成结尾字幕。口号可以作为总结，但不能替代剧情中的选择、行动和代价。

### 不采用方案二：固定坏人型

不把每个档案都写成老姚抓捕非法捕捞者。该做法容易脸谱化，也会把水域生态问题缩窄成单一反派问题。违法捕捞可以成为部分档案的重要原因，但不能取代栖息地、污染、外来物种、繁殖期干扰、废弃渔具和错误放流等议题。

## 三、账号人设与品牌核心

### 老姚的公开人设

- 身份：懂钓鱼的异常水域调查员、文明垂钓守水人。
- 专业基础：会看漂、识水层、判断鱼情、调整线组和控制鱼体受力。
- 价值底线：守法规、认鱼种、护繁殖、少伤害、留证据、不逞强。
- 人物魅力：嘴硬、接地气、有经验，但愿意承认误判并为正确选择付出代价。
- 禁止塑造：道德完人、执法人员、全知专家、私刑英雄、所有鱼都无条件放流的人。

### 固定栏目记忆

主栏目名：`异常水域档案`  
主价值语：`钓的是答案，不是战利品`  
人物价值语：`能钓上来是本事，知道什么时候放手是规矩`  
单集处置流程：`认鱼种 -> 查规则 -> 判伤情 -> 正确处置 -> 留存证据`

### 收藏价值载体

每个档案除故事正片外，可裂变一张“守水档案卡”，只保留经核验的信息：

- 水域与当地规则范围。
- 本集鱼种或生态现象。
- 保护、禁钓或外来物种状态。
- 误钓后的正确处置。
- 本集钓鱼知识。
- 官方核验来源和核验日期。

## 四、世界观升级

### 三层世界模型

世界底层由三个层级构成：

1. 现实水层：真实水域、真实生物和现实生态问题所在的物理层。
2. 水域记忆层：保存水温、流速、声音、气味、迁徙路线、伤痕和生态关系等局部“水痕”的信息层。
3. 第二水系：跨越现实流域边界的隐秘连通关系，通常传递水痕，极端情况下造成真实活体错流。

主回流的本质是一次水域自我修复失败。第二水系依据历史水痕尝试恢复被截断的旧流路、迁徙路线和生态联系，但现实水系、物种分布和人类活动已经改变，因此产生错误重叠、水痕重放和活体错流。

主回流发生于1975年8月上旬河南驻马店特大暴雨洪水期间。该真实灾难只作为历史与极端水文背景，异常不得成为现实灾害的虚构成因，不直接复刻溃坝、伤亡、逃生和真实受灾者经历，不把真实水库或遗址包装成怪鱼关卡。

现实天气采用权威气象口径：深入内陆的台风天气系统输送大量水汽，与冷空气、当地地形抬升等共同造成持续极端暴雨；不得简写成“异常力量引来暴雨”或单一“积雨云作怪”。

上一任守水人面对的并非100个天然节点。他未能彻底解决主回流，只能将其分散、压低和延后。100份档案由老姚团队人为编号，用于还原主回流的分散路径。第二水系本身不是敌人，终局不得简化为消灭异常或永久封闭全部接口。

上一任守水人的分流方法固定为“活体归源 → 水痕分汊 → 错峰封窗”。三段方法必须通过物种来源、水文记录、流向、水位、温差和有限校准表现；万水竿不是容器，不承载主回流、怪鱼、灵魂或完整人格。禁止扩展为法阵、咒语、能量对抗、空间裂缝和献祭体系。

上一任守水人固定名为江流，是1975年约40岁的断桥水库调查员兼民间老钓手。断桥水库完全虚构，不映射现实板桥水库。万水竿曾提前预警，但江流因雨量、水位、巡查和联络工作繁忙，将预警归入普通洪前变化，延迟异常处置；误判不造成或加重现实洪灾。完成主体分流后，他参加现实救援，先救群众，最后为救老高力竭牺牲，不得改写为献祭或异常反噬。

老高固定为1965年生、事发时10岁的童年目击者，后成为基层水利工作者；他是老姚母系长辈，但不能承担当年的专业判断。老高不喜欢钓鱼，不是老钓手，也不是中间一任守水人。

江流救援造型固定为无军衔、无徽章的橄榄绿防水工作服。他不是军人；真正的解放军救援人员作为群体出现，橄榄绿承担“人民子弟兵来了、军民共同救人”的正向记忆意象。禁止给江流添加军衔、军徽、红星帽徽或虚构部队番号。

历史救援只通过老高三段克制记忆呈现：工作台上被忽视的预警、雨幕中的橄榄绿救援群像、江流把老高递交给救援人员后消失。禁止复刻真实溃坝和群体伤亡画面。

硬边界：水域记忆层不能制造或复活生命；实体异常必须存在现实来源、第二水系错流通路或人为转移路径；摄像机只记录层级间的时间差或相位差；万水竿只校准、识别和短暂稳定边界。

### 百档案结构

- 70份现水档案负责建立现实水域、物种/群落、生态问题和原始证据。
- 20份回声档案负责调用旧物种、旧证据、旧地点或旧关系，完成误读、修正和伏笔回收。
- 10份汇流档案分别位于十卷卷末，汇总证据、给出卷级答案并触发下一卷。
- 每卷默认采用“7现水 + 2回声 + 1汇流”。
- 现水档案不强制对应70种唯一动物，更不要求100种动物逐一对应100份档案。

### 万水竿的新解释边界

万水竿不是违法行为探测器，也不对人物作道德裁判。它只能感知水层、水温、水流、鱼线承压、生物靠近和异常生态压力留下的变化。

万水竿传承固定为：江流牺牲后留在其住处；老高灾后随大人收拣遗物时得到并长期保管，但未获认可；1996年出生的老姚在小学某个暑假到姥姥家，因喜欢钓鱼从老高处得到此竿。老高称其为“破鱼竿”只表示陈旧久置，不表示物理损坏。童年交接后只形成长期使用适配，档案001复合条件重叠时才解除封存、第一次明确显性激活并让老姚感知老莽头。

来历前置链固定为：确山人江流在1958年以后至1960年代前期赴东北祭拜同乡抗日英雄杨靖宇，返乡途中从东北普通旧货市场偶得万水竿并带回确山。只确认万水竿原产东北，具体制作地点和更早来源不明。不得将其写成杨靖宇、东北抗联、烈士陵园或殉国地相关遗物。

档案001“无声湖”固定为断桥水库西北侧封闭静水湾的摄制组档案代称。解除封存必须同时满足：老姚热爱钓鱼并长期适配、断桥水库、农历初一暗月之夜、线组取得对应军鱼鳞片、手掌微小伤口的极少量血迹进入原有水纹，以及匹配旧窗口的水域条件。军鱼本体无需出水，老姚仍然空军；现场只记录“疑似鳞片”。任何单项都不能独立触发；血迹不是血脉、祭品、能量或力量来源，禁止割掌、滴血仪式和血色光效。

老莽头此前一直随万水竿封存，条件未满足时无法苏醒或被感知；其东北口音来自万水竿地域印记。农历初一暗月之夜、军鱼与鳞片接触方式不得被下游 Agent 改换；不得为了触发把军鱼本体钓上岸，也不得取消原有空军结局。

因此，任何下游故事不得把“保管、长期适配、解除封存、显性激活、器灵开口”改写成血脉认主，不得将传承解释为高家血脉继承，也不得让老高曾经使用万水竿执行守水任务。

因此：

- 它可以感知水域秩序失衡后的异常反应。
- 它不能直接说出“有人电鱼”“这条鱼是保护动物”。
- 违法证据和物种判断必须来自老姚、林溪、成年后的老高、影像资料和官方核验；老高的75·8童年记忆只能作为待校正证词。
- 破局必须依靠真实调查、专业判断和正确处置。

### 怪鱼角色分类

怪鱼不再默认等于需要征服的敌人，可分为：

1. 生态受害者：受到污染、误捕、废弃渔具或栖息地破坏影响。
2. 水域指标物种：其出现、消失或行为变化反映水域状态。
3. 异常入侵者：威胁本地生态，不能以“爱护生命”为由随意放流。
4. 水域守护者：外表危险，但其行为与繁殖地或生态边界有关。
5. 真正危险目标：会主动伤害人或破坏生态，需要隔离、上报或封存。

### 总主线升级

旧主线：追查 100 起怪鱼事件。  
新主线：追查 100 起异常水域事件，判断每个目标应当观察、救助、放流、隔离、上报还是封存。

第一季共同谜团升级为：

> 多起异常中的同一种水纹，并不是“有大鱼”的标记，而是第二水系尝试恢复旧联系时留下的水痕。上一任持竿人没有彻底封死它们，而是主动分流，以长期异常换取当时整体水系没有崩溃。

## 五、单集双引擎结构

每个档案必须同时具备两条可独立复述的线：

- 传播线：水下到底发生了什么？
- 价值线：面对这个目标，老姚应该钓、放、救、报还是停？

如果只有传播线，内容会变成怪鱼猎奇。  
如果只有价值线，内容会变成说教科普。  
两条线必须在高潮处汇合为一次有代价的选择。

## 六、单集六拍模板

| 节拍 | 建议时段 | 必须回答的问题 | 观众价值 |
|---|---:|---|---|
| 1. 反常结果 | 0-2 秒 | 眼前哪里违反常识？ | 停留与记忆锚点 |
| 2. 调查承诺 | 2-10 秒 | 老姚必须查清什么，失败会失去什么？ | 目标与代价 |
| 3. 常规判断 | 10-25 秒 | 正常钓鱼经验如何解释？ | 专业参与和收藏 |
| 4. 证据打脸 | 25-40 秒 | 哪个可见证据推翻第一次判断？ | 认知修正 |
| 5. 艰难选择 | 40-65 秒 | 钓获、流量、装备和保护之间怎么选？ | 人物立场与高潮 |
| 6. 处置回报 | 65-80 秒 | 正确行动解决了什么，又留下什么谜团？ | 情绪回报、知识与追更 |

### 两秒记忆锚点标准

两秒锚点必须同时满足：

- 静音观看也能理解异常。
- 只出现一个主要动作和一个主要矛盾。
- 与本集后续因果直接相关。
- 能压缩成不超过十个字的口头表达。
- 不依赖虚假夸张、违法演示或未核验物种身份。

档案001暂定锚点：

> 漂没动，线动了。

该锚点仍需在档案001正文重构时验证，不能反过来支配不合理剧情。

## 八、法律与科学表达边界

### 禁止笼统表达

- 不把所有网具、矛具一概写成违法，应使用“非法网捕”“禁用渔具”“违规锚矛鱼”等经核验表述。
- 不把“珍稀”自动等同于“国家重点保护”，必须查官方名录和地方规则。
- 不把真正已经灭绝的物种轻易写成重新发现。现实物种优先使用“曾被认为在该流域消失”“极危”“疑似历史分布种群”等准确表达。
- 不宣传“所有鱼都应放流”。重点保护本土物种、受伤个体、禁钓品种、幼体和外来物种的处置逻辑不同。
- 不展示电、毒、炸、禁用网具和违规锚矛鱼的可复现操作步骤。

### 单集制作前核验项

1. 水域是否允许垂钓，是否处于禁钓区或禁钓期。
2. 当地允许的竿、线、钩数量和钓法。
3. 目标物种的准确中文名、学名和识别特征。
4. 国家或地方保护等级及名录版本。
5. 是否属于外来物种及当地处置要求。
6. 误钓、受伤、死亡或被困个体的合法处置流程。
7. 是否涉及应当模糊处理的敏感栖息地坐标。

### 当前官方依据

- 《中华人民共和国渔业法》：禁止炸鱼、毒鱼、电鱼等破坏性捕捞方式，并要求遵守禁渔区、禁渔期和禁用渔具规定。
- 《中华人民共和国水生野生动物保护实施条例》：误捕水生野生动物应立即无条件放生；受伤、搁浅或被困个体应及时报告并实施专业救护。
- 农业农村部关于长江流域禁捕水域垂钓管理的意见：重点保护水生野生动物误钓后应立即放回原水体，明显受伤应报告；外来物种不得放归天然水体。

每个现实物种和现实水域在制作时必须重新核验，不能只依赖本规范中的原则性摘要。

## 九、内容产品矩阵

每个档案最多裂变四种内容，避免为填账号而重复生产：

1. 60-90 秒剧情正片：完成异常调查和人物选择。
2. 10-20 秒高能切片：只保留本集两秒锚点和关键反转。
3. 20-40 秒知识复盘：解释真实钓鱼判断和正确处置。
4. 单页守水档案卡：用于收藏，标注核验来源和日期。

商业内容只能进入知识复盘或自然剧情节点，不得让产品替代生态选择，也不得用保护鱼种、违法捕捞或救助事件强行带货。

## 十、档案与脚本验收标准

每个档案必须全部通过：

- 两秒异常在静音状态下可理解。
- 15 秒前建立明确调查目标和失败代价。
- 第一判断有现实专业依据，而不是故意犯蠢。
- 异常证据与最终结果存在因果关系。
- 高潮包含一次有损失的选择。
- 正确处置由行动体现，不靠长篇训话。
- 至少提供一个可收藏的真实知识点。
- 至少推进一个第一季共同谜团。
- 物种、法规、水域和钓法均完成来源核验。
- 不冒充真实新闻，不公开敏感坐标，不鼓励用户自行执法。

任何一项不通过，不进入 Seedance 分镜和视频生成阶段。

## 十一、旧资产处置原则

- V2.0 已生成的角色图、场景图和色卡可进入复用候选池，但必须重新检查角色、装备、数量和场景连续性。
- 四个关键镜头只作为试跑样片，不默认复用；包含“六支浮漂”的镜头直接淘汰，其余镜头必须在V2.1正文因果成立后逐条决定。
- 现有档案001故事、脚本、分镜、提示词和审核结论标记为“V2.0 试跑资产”，不再视为V2.1生产依据。
- 不覆盖旧文件；V2.1 使用新文件名和版本号，便于比较和回溯。
- “六支浮漂”等违反一竿一漂设定的内容必须在V2.1中删除。

## 十三、成功标准

V2.1优化完成后，应当能够回答：

- 观众为什么在两秒内停留？
- 本集的怪鱼问题与现实生态问题有什么因果关系？
- 老姚为自己的价值观付出了什么代价？
- 观众看完学会了哪个可执行且合法的判断？
