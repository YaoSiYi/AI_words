# 03 鱼种资产规则

## 鱼种规划原则

采用“100种候选鱼库 + 30种重点鱼库 + 6种第一季验证鱼种”。

当前阶段只建立规则和第一季验证骨架，禁止在试播验证前批量生成100集完整剧本。

## “最字标签”原则

每条核心鱼种必须有一个真实、清晰、可验证的“最字标签”，让观众一秒明白它为什么值得看。

标签类别：

1. 体型之最：最大、最重、爆发力最强。
2. 外形之最：最像远古生物、最透明、牙齿最特殊。
3. 行为之最：最会伏击、伪装、迁徙、发声或护幼。
4. 垂钓之最：最难中钩、最易切线、最考验卸力或远投。
5. 地域文化之最：最能代表某条江河或地方传说。
6. 食用经济之最：合法前提下最具地方美食、养殖或市场话题。

“最好吃”只能用于依法允许捕捞、养殖和食用的鱼种，禁止对珍稀、保护、禁捕鱼种进行食用诱导。

## 每条鱼必须回答

1. 它“最”在哪里？
2. 第一眼为什么值得看？
3. 它能教给钓友什么？
4. 它能自然承接什么装备或商业内容？
5. 它的保护等级和当地捕捞规定是什么？

## 内容等级

| 等级 | 价值 | 用途 |
|---|---|---|
| S | 最大、最凶、最怪、最难钓、最罕见 | 爆款、季终高潮 |
| A | 最漂亮、最好玩、行为最特殊 | 视觉传播、机制剧情 |
| B | 合法前提下最好吃、最有地域经济价值 | 美食、地域、商业话题 |
| C | 钓法最特别、装备要求最明确 | 教程、测评、带货 |

第一季不得六集全用S级鱼，必须留出升级空间。
