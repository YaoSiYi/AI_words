# 01 人物母文件

## 人物关系总纲

老姚看漂，林溪看证据，老高看水也看旧记忆，小黄看危险，老莽头看命。

## 老姚：主角 / 行动与现代钓技

- 身份：1996年出生的经验丰富钓鱼人，姓名沿用姚逸姚，外号老姚。
- 性格：专业、接地气、不装腔；遇到异常会害怕、犹豫和嘴硬。
- 能力：现代钓法、临场判断、快速试错、线组调整、控鱼。
- 缺陷：相信经验与手感，有时低估无法量化的异常。
- 不知道：万水竿真正来历和上一任持竿人的结局。
- 童年经历：小学某个暑假到姥姥家，因喜欢钓鱼从老高处得到被称为“破鱼竿”的万水竿；他只知道自己从小用惯此竿，长期使用形成适配，但封存直到档案001才解除。
- 禁止：全知全能、永不空军、换装备必上鱼。

## 小黄：小狗 / 本能与情感

- 日常功能：陪伴、轻喜剧、空军情绪缓冲。
- 调查功能：拒绝靠近异常水域、对无人方向低吼、提前察觉异常气味。
- 世界观功能：只对被万水竿标记过的异常产生反应。
- 禁止：开口说话、变成灵兽、直接指出答案。

## 老莽头：器灵 / 规则与秘密

- 掌握：部分异常规则、旧档案、上一任持竿人线索。
- 口音：克制东北口音，来自万水竿东北地域印记；具体城市来源不锁死。
- 沉默原因：档案001前一直随万水竿处于封存状态，无法苏醒、说话或被感知，不是故意旁观多年。
- 作用：有限提示、反差幽默、长线伏笔。
- 缺陷：傲慢、隐瞒、不能完全信任。
- 禁止：成为万能百科和解题机器。

## 林溪：调查员兼纪录片摄影师 / 证据与理性

- 年龄：26-32岁。
- 身份：自然纪录片摄影师、水域调查记者或生态影像记录者。
- 性格：理性、谨慎、证据意识强，不轻信怪鱼传闻。
- 能力：摄像、录音、水下设备、资料检索、证据归档。
- 缺陷：钓鱼实战经验不足，早期过度相信设备。
- 目标：找到可以公开验证的证据。
- 长线秘密：过去拍摄的旧素材里曾出现万水竿水纹。
- 与老姚关系：互不完全信任的合作伙伴；第一季不主动发展爱情线。

林溪必须对调查结构不可替代，禁止仅作为颜值、恋爱或被救角色。

## 老高：母系长辈、退休基层水利工作者 / 水情与童年记忆

- 出生：1965年；1975年时10岁。当前准确年龄随小说现实年份确定。
- 亲缘：老姚母亲姓高；老高是母亲高家一侧的长辈，具体辈分称呼待定。
- 经历：童年喜欢跟在江流身后；灾后随大人到江流住处收拣遗物，得到并长期保管万水竿；成年后进入基层水利岗位。
- 能力：识水位与洪痕、判断天气、熟悉老河道、基层水利记录与地方传闻。
- 性格：寡言、固执、经验极强，回避旧事。
- 缺陷：依赖传统水情经验，不熟悉现代设备；因幸存者愧疚回避关键证词。
- 钓鱼边界：不喜欢钓鱼，不是老钓手；保管万水竿多年却未获认可，也从未成为守水人。
- 记忆边界：当年只是孩子，没有参与专业判断或三段分流；具体物件与动作可能可靠，因果解释可能错误。
- 长线秘密：知道江流死于75·8洪水并认得万水竿，却长期隐瞒江流最后为救自己牺牲，把完整旧事压缩成普通的看水失误。
- 交接经历：1996年出生的老姚在小学某个暑假到姥姥家想钓鱼，老高把家中久置的万水竿当“破鱼竿”交给他；“破”只表示陈旧，不表示竿体损坏。
- 与老姚关系：母系长辈与晚辈，兼具亲缘信任和经验冲突；不是全知师父与徒弟。

## 江流：断桥水库调查员兼老钓手 / 上一任守水人

- 姓名：江流。
- 年龄：1975年约40岁。
- 时代身份：完全虚构的断桥水库基层调查员，同时是长期在当地河网作钓的民间老钓手。
- 籍贯与得竿：河南确山人；1958年以后至1960年代前期赴东北祭拜同乡抗日英雄杨靖宇，返乡途中从东北普通旧货摊或旧货市场偶得万水竿并带回确山。
- 来历边界：万水竿不是杨靖宇、东北抗联或纪念设施遗物；江流不知道旧货市场以前的来源。
- 水文能力：人工观测水位、雨量和流向，巡查河段、洪痕与旧河道，整理基层水文记录。
- 鱼情能力：识别鱼层、鱼星、洄游、繁殖期与异常逃散，能从活体反应修正单纯依赖仪器的判断。
- 三段分流依据：以旧水文图、水位与流向记录确定河道关系，以鱼群状态判断活体风险，再以万水竿有限校准异常连接。
- 人物价值：证明守水不是神秘血统，而是观察、记录、判断和承担后果；同时留下一个不完整、需要老姚修正的旧方案。
- 关键误判：万水竿曾提前预警，但他忙于雨量、水位、巡查和联络，将预警与鱼群逃散归入普通洪前变化，没有及时复核。
- 最后行动：洪灾来临后意识到误判，完成主体分流，随后穿无军衔、无徽章的橄榄绿防水工作服加入军民救援；先救群众，最后为救老高力竭牺牲。
- 视觉边界：江流不是军人；橄榄绿是老高记忆中人民子弟兵和所有救援者共同构成的颜色意象。
- 禁止：写成教授、全知科学家、防汛调度指挥者、法师或万水竿答案接收器。
- 禁止：让他改变现实洪水流向，或让主回流成为真实洪灾的成因和放大器。
- 禁止：让他的误判造成、放大或解释现实洪灾；他误判的是异常预警的归属与优先级。
- 禁止：给江流添加军衔、军徽或解放军身份；不得用个人英雄覆盖解放军、地方救援者和群众共同救援。
- 禁止：把10岁的老高写成专业分流参与者，或默认上一任与老高存在血缘关系。
- 待确认：具体出生年、性格缺陷、与老莽头的具体关系、万水竿为何留在住处而未被江流带入救援现场。

## 第一季登场顺序

1. 第1-2集：老姚、小黄、摄制组画外音；老莽头只出现一次声音或反应。
2. 第2-3集：林溪从幕后摄影者正式成为调查者。
3. 第3-4集：老高作为老姚母系长辈进入，见到万水竿后拒绝解释，并留下相互矛盾的童年旧事线索。
4. 第5-6集：五人关系形成，但不要求每集全员出现。
