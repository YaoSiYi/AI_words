# 00 世界观母文件

## 核心明线

老姚是一名经验丰富、接地气的钓鱼人。摄制组最初只记录他的野钓日常、鱼情判断、装备使用和空军经历，后来陆续收到异常水域线索：集体停口、固定时间黑漂、鱼群消失、反常切线、不属于当地的巨大水下轮廓。

每次进入异常水域，被称为“万水竿”的旧鱼竿都会产生无法解释的反应。

## 核心暗线

万水竿不是帮助主人多钓鱼的神器，而是在寻找、识别和校准发生重叠的水域边界。

老姚认为自己在调查怪鱼，后来发现部分怪鱼是活体错流的受害者，部分“注视”则是水域记忆借鱼线、水波和摄像设备对观察作出的回声。

## 世界底层三层模型

1. **现实水层**：真实水域、真实生物、现实生态问题和全部物理后果所在层。
2. **水域记忆层**：保存水温、流速、声音、气味、迁徙路线、伤痕、死亡瞬间和群落关系等局部“水痕”的信息层。
3. **第二水系**：跨越现实流域边界的隐秘连通关系，通常只传递水痕，极端情况下造成真实活体错流。

主回流的本质是一次水域自我修复失败。第二水系依据历史水痕，试图恢复被现实截断的旧流路、迁徙路线和生态联系；由于现实水系、物种分布和人类活动已经改变，修复过程产生错误重叠、水痕重放和活体错流。

主回流发生于1975年8月上旬河南驻马店特大暴雨洪水期间。现实气象采用“深入内陆的台风天气系统输送水汽，与冷空气、当地地形抬升等共同形成持续极端暴雨”的权威口径。真实洪灾只作为极端水文与历史背景，正式内容不得暗示异常造成或加重现实灾害，也不得直接复刻溃坝、伤亡、逃生和真实受灾者经历。

上一任守水人名叫江流，是1975年约40岁的断桥水库调查员兼民间老钓手。断桥水库完全虚构，不映射现实板桥水库。江流是确山人；1958年以后至1960年代前期，他赴东北祭拜同乡抗日英雄杨靖宇，返乡途中从东北普通旧货市场偶然得到万水竿并带回确山。万水竿只确认原产东北，具体制作地和更早经历无从得知，也不是杨靖宇、抗联或纪念设施相关遗物。万水竿曾在洪灾前发出异常预警，但江流忙于雨量、水位、巡查和联络，将预警与鱼群逃散归入普通洪前变化，没有及时复核；改判后，他将主回流分散、压低和延后。完成主体处置后，江流加入军民现实救援，先救群众，最后为救10岁的老高力竭牺牲。万水竿留在江流住处，灾后由老高得到并长期保管；1996年出生的老姚在小学暑假得到此竿并形成长期适配。档案001中复合条件完整重叠后，万水竿才第一次解除封存并让老姚感知老莽头。后续各地异常并非100个天然节点逐个失效，而是同一主回流的分散后果。

### 不可突破的底层限制

- 水域记忆层不能凭空创造生命、复活死亡生物或稳定复制完整意识。
- 实体生物必须具有现实来源、错流通路或人为转移路径。
- 纯水痕只能形成影像、声音、路线、行为残响或设备数据异常。
- 每次异常必须具有现实生态诱因、有限持续时间和可调查后果。
- 摄像机只可能记录层级间的时间差或相位差，不保证影像完整或解释正确。
- 万水竿只能校准、识别和短暂稳定边界，不能制造第二水系。
- 第二水系只能参考历史水痕，不能理解当代法律、人工水利边界、保护等级和新的生态平衡；旧路不天然等于正确道路。
- 历史背景只通过旧水文记录、日期、残缺影像、水位痕迹和人物证词间接呈现；主回流核心异常点必须小说化。
- 上一任守水人依次采用活体归源、水痕分汊和错峰封窗。三段方法只作用于第二水系连接关系，万水竿只作有限校准，不承载主回流或人格。
- 正式内容保持低玄幻：分流通过水文资料、物种来源、流向、温差、水位和人物操作表现，禁止法阵、咒语、能量洪流、空间裂缝和灵魂献祭。
- 上一任守水人不是教授、全知科学家或现实防汛调度指挥者；不得让他从万水竿直接获得物种、来源或处置答案。
- 江流的误判只影响第二水系处置时机，不造成或加重现实洪灾；他的死亡发生在完成分流后的现实救援中，不得写成献祭、反噬或万水竿索命。
- 老高生于1965年，事发时10岁，只能提供碎片化童年目击，不能被写成三段分流参与者或全知证人。
- 老高不是老钓手，也不是中间一任守水人；长期保管万水竿不等于获得认可。
- 档案001的“无声湖”固定为断桥水库西北侧封闭静水湾的摄制组档案代称，不是独立湖泊。
- 解除封存必须同时满足长期钓鱼适配、断桥水库、农历初一暗月之夜、线组取得对应军鱼鳞片、手掌微伤的极少量血迹进入原有水纹和匹配旧窗口的水域条件。军鱼本体无需出水，老姚仍然空军；血迹不是血脉、祭品或能量，禁止主动割伤和滴血仪式。
- 老莽头此前因万水竿封存而无法苏醒或被感知；东北口音来自万水竿的东北地域印记，具体城市与更早主人不得擅自确定。
- 江流不是军人。橄榄绿服装必须无军衔、无徽章；真正的解放军救援人员以群体形象出现，突出军民协作和生命优先。

## 现实与异常边界

- 观众不能完全确认事件是真实、梦境还是异常空间。
- 老姚可以短暂断片或记忆缺失，但不能每集固定睡着穿越。
- 摄像机、录音、鱼线、鳞片、水样等必须留下证据。
- 每集至少保留一个现实层无法彻底解释的细节。
- 异常必须从真实鱼情问题中生长，不能凭空出现。

## 万水竿

一根具有年代感和使用痕迹的旧鱼竿：握把磨损、竿身存在细小水纹，无现代游戏武器外观。激活时只出现克制的淡蓝水纹、细微震动和低频共振，禁止玄幻光柱。

传承固定为：江流东北旧货市场偶得并带回确山 → 江流住处遗物 → 老高灾后保管但未获认可 → 童年老姚在姥姥家暑假得到并形成长期适配 → 档案001复合条件解除封存。老高口中的“破鱼竿”不表示折断、缺节或不可使用。保管、适配、解除封存、显性激活和器灵开口不得改写成血脉认主。

能力：

1. 感知异常水层。
2. 感知鱼线承压变化。
3. 感知局部水温与水流异常。
4. 感知目标鱼靠近。
5. 感知危险生物或异常水域。
6. 通过有限反应给出方向性提示。

限制：

- 每次调查最多三次明确反应。
- 只能提示方向，不能给出答案。
- 不能自动上鱼、控鱼或替代老姚操作。
- 不能保证成功，允许空军、切线、爆竿和误判。
- 破局必须由真实钓鱼知识与操作完成。

## 老莽头

老莽头代表“规则与过去”，不是系统说明书。

- 嘴硬、讽刺、说话只说半截。
- 知道部分异常规则和上一任持竿人的经历。
- 经常隐瞒，但不能为了反转随意说谎。
- 每集最多出现1-3次，不得替代老姚判断。

禁止完整播报任务、奖励、等级、经验、商城和战斗力。
