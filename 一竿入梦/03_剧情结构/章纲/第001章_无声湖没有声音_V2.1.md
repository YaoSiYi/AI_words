# 第001章：无声湖没有声音

版本：V2.1  
状态：正文生产依据  
上位依据：`第一卷_空军者的试炼_V2.1章纲.md`、`档案001_无声湖停口事件_V2.1.md`

## 本章职责

- 建立断桥水库西北静水湾夜钓现场、“无声湖”临时档案名和摄制组跟拍关系。
- 通过凉茶、空鱼护、饵料和小黄等生活细节写出老姚空军三小时后的嘴硬与疲惫。
- 让老姚完成一次正常的初步鱼情排查，证明他有经验，但不在本章给出异常答案。
- 让环境声音逐渐减少，小黄先于人表现出退缩。
- 章末只交付第一个明确矛盾：浮漂固定，竿尖至浮漂之间的风线却向侧面移动。

## 场景边界

- 时间：农历初一暗月之夜，凌晨一点多。
- 地点：断桥水库西北静水湾；“无声湖”为摄制组隐去坐标使用的临时名称。
- 出场：老姚、小黄、摄制组拍摄人员。
- 器材：一根万水竿、一个浮漂、一套台钓线组、主摄影机；水下设备本章不提供答案。
- 人物认知：老姚仍把万水竿当作长期使用的普通旧手竿，不知道老莽头存在。

## 情绪递进

`熬夜空军的无聊 -> 被拍摄后的嘴硬 -> 按经验复核的认真 -> 环境失声带来的纳闷 -> 小黄退缩后的不安 -> 风线横移时的专注`

## 必须保留

- 鱼护严格为空。
- 水面有零散鱼星，但没有有效漂相。
- 老姚先检查饵料、到底状态和轻微走水等正常原因。
- 小黄只用动作预警，不承担答案功能。
- 摄像机是有限见证者，不以连续问答推动剧情。
- 结尾浮漂保持三目半，风线横向移动；不出现蓝白浮漂光、系统面板、任务或入梦。

## 不得提前

- 不展示半透明旧线和疑似鳞片的完整答案。
- 不解除万水竿封存，不让老莽头开口。
- 不揭示军鱼、复合触发公式、水域记忆层、第二水系或江流。
- 不让老姚直接得出“有怪鱼”的结论。

## 下一章接口

老姚首先把风线横移归入风、轻微走水或线组状态问题。第002章围绕“第一次异常后的复核”展开：查饵、查漂、查钓层并留下连续参照；正常解释再次失败，窝边小鱼活动逐步退出。
