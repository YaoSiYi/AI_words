# 章纲

V2.1正文级章纲优先使用带版本和项目名的文件，例如：

```text
第一卷_空军者的试炼_V2.1章纲.md
```

V2.1当前活跃文件：

- `第一卷_空军者的试炼_V2.1章纲.md`
- `档案001_无声湖停口事件_V2.1.md`
- `第001章_无声湖没有声音_V2.1.md`

目录中原有的 `第001章_三小时没口.md`、`第002章_浮漂往天上走.md` 等单章文件属于V1旧方案素材，保留但不得直接作为V2.1生产依据。后续V2.1单章章纲必须带 `_V2.1` 后缀，并以本README中的活跃文件清单为准。

章纲建议包含：

- 本章目标。
- 出场角色。
- 场景地点。
- 冲突推进。
- 新增信息。
- 结尾钩子。
- 本章会影响的状态快照。
