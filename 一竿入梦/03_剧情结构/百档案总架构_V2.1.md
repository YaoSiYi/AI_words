# 《一竿入梦》V2.1百档案总架构

版本：V2.1架构设计稿  
确认日期：2026-07-17  
当前状态：总体结构与世界底层真相已确认；卷级答案、卷名和具体档案内容待分阶段确认

## 一、已确认的总体架构

- 全书采用 **10卷 × 每卷10份档案**，共100份异常水域档案。
- 每卷必须拥有独立调查方向、生态主题、人物阶段变化和卷末真相。
- 每份档案可以提供相对完整的局部故事，但不能查完即归零；证据、人物、地点或后果至少有一项进入后续档案。
- 卷内采用递进式结构，卷间采用后果接力，六条长线谜团贯穿全书。
- 100份档案不一次性铺满标题。依据已确认的世界真相，先确定十卷主题、卷末答案和伏笔节点，再逐卷细化。
- 档案差异不依赖“换一条更大的怪鱼”，而来自水域类型、现实钓鱼问题、异常机制、生态议题、证据形式、人物选择和调查后果的组合变化。
- 100份档案固定细化为 **70份现水档案 + 20份回声档案 + 10份汇流档案**。
- 每卷默认采用 **7现水 + 2回声 + 1汇流**，既扩展真实生态世界，也承担伏笔回收和卷级推进。
- 100是调查团队的人为编号规模，不是世界天然存在的100个关卡或100个独立节点。

## 二、世界底层真相

所有现实水域可能通过“第二水系”发生短暂重叠。现实水层承载真实水域和生物；水域记忆层保存温度、流速、声音、气味、迁徙路线、伤痕与生态关系形成的“水痕”；第二水系负责在不同水域间传递水痕，并在极端条件下造成真实活体的错流。

主回流的本质是水域自我修复失败。第二水系依据历史水痕尝试恢复被截断的旧流路、迁徙路线和生态联系，却无法识别现实水系、物种分布和人类活动已经发生的变化，最终形成错误重叠、水痕重放和活体错流。

主回流发生于1975年8月上旬河南驻马店特大暴雨洪水期间。真实洪灾只作为历史和极端水文背景，异常不能被写成灾害成因或加重灾害的隐秘力量，历史部分以档案证据和人物证词间接呈现。

上一任守水人名叫江流，是1975年约40岁的断桥水库调查员兼民间老钓手。断桥水库完全虚构。万水竿曾在洪灾前预警，但江流忙于雨量、水位、巡查和联络，将其归入普通洪前变化，没有及时复核；改判后，他面对一次大规模“主回流”，最终选择将其分散、压低和延后。完成主体处置后，江流转入军民共同救援，先救群众，最后为救10岁的老高力竭牺牲。万水竿随后从江流住处被老高收存；老高不喜欢钓鱼也未被认可，后来将它交给小学暑假到姥姥家钓鱼的老姚。老姚团队记录的100份档案，是为了追踪这些分散后果并还原完整关系图。

底层硬约束：

- 水域记忆层不能凭空创造生命，也不能复活死亡或灭绝生物。
- 实体异常生物必须存在现实来源、错流通路或人为转移路径。
- 记忆残响可以形成影像、声音、路线或行为重放，但不能稳定还原完整意识。
- 每次异常都必须拥有现实生态诱因、有限持续时间和可调查后果。
- 摄像机记录的是层级间的时间差或相位差，不是无条件拍到真相。
- 万水竿负责校准、识别和短暂稳定边界，不负责制造异常或直接解释答案。

## 三、70+20+10档案构成

| 类型 | 数量 | 核心职责 | 物种使用原则 | 长线功能 |
|---|---:|---|---|---|
| 现水档案 | 70 | 引入新的现实水域问题、核心物种/群落或生态关系 | 不强制70种唯一动物；允许围绕同一物种的不同现实问题，但主冲突不得重复 | 建世界、建证据、建人物关系 |
| 回声档案 | 20 | 让旧物种、旧证据、旧地点或旧生态关系在新状态下重现 | 原则上不靠新增怪鱼制造看点；至少回扣一份既有档案 | 埋坑、误读、部分回收、反转 |
| 汇流档案 | 10 | 汇总本卷多份证据，给出卷级答案并产生不可撤销后果 | 可以没有新物种，也可以以群落或整片水域为调查对象 | 改变主线、触发下一卷 |

物种总量采用“约70个核心物种/群落候选池、按核验逐卷启用”的管理方式，不要求100种水生动物一一对应100份档案。保护、濒危和敏感物种通过监测、救助、环境DNA、历史影像或专业协作进入故事，避免把钓获作为唯一叙事动作。

## 五、每卷十档案的固定节奏

| 档案位置 | 结构职责 | 要求 |
|---:|---|---|
| 第1档 | 现水 / 新卷入口 | 用一个强异常建立本卷新方向，同时承接上卷后果 |
| 第2档 | 现水 / 规则扩展 | 展示同一方向的第二种表现，避免把首档当作孤例 |
| 第3档 | 现水 / 人物卷入 | 让一名核心角色的私人目标与本卷问题发生关系 |
| 第4档 | 回声 / 旧证据回流 | 前卷或更早的证据重新出现，并获得新的解释 |
| 第5档 | 现水 / 中段代价 | 调查成功但人物失去资源、信任、证据或安全边界 |
| 第6档 | 现水 / 阶段答案 | 给出一个足以说服人物和读者的阶段性解释 |
| 第7档 | 现水 / 连续事件上篇 | 新证据证明阶段答案只对一半 |
| 第8档 | 回声 / 连续事件下篇 | 让旧案在新水域产生因果反转，完成一次明确回收 |
| 第9档 | 现水 / 卷级真相入口 | 揭开本卷核心答案，同时让更大的长线问题成形 |
| 第10档 | 汇流 / 卷末高潮 | 汇总本卷证据，由人物作出有代价的选择，后果直接触发下一卷 |

此节奏是结构职责，不是机械模板。允许调整具体表现，但不得让连续多档都停留在“到水边、发现怪鱼、专业破局、得到鳞片”的重复循环。

## 六、档案差异化矩阵

规划每份档案时，至少从下列七个维度形成新的组合：

| 维度 | 候选方向 |
|---|---|
| 水域 | 野河、湖泊、水库、沼泽、峡谷、地下河、冰湖、黑水河、城市河网、潮汐河口等 |
| 现实问题 | 停口、切线、闹窝、走水、鱼层错判、窗口期、溶氧、温差、回流、障碍区等 |
| 异常方式 | 声音消失、时间错位、鱼群行为反常、物种错位、水纹重复、影像缺帧、旧河道重现等 |
| 生态议题 | 栖息地破坏、外来种、废弃渔具、污染、繁殖场干扰、过度捕捞、坐标泄露等 |
| 证据形式 | 影像、录音、鱼线、水样、鳞片、设备数据、旧照片、地方档案、目击证词等 |
| 价值选择 | 钓、停、放、救、报、隐去坐标、放弃流量、保护证人、公开部分真相等 |
| 人物焦点 | 老姚专业修正、林溪证据边界、老高旧事、小黄预警、老莽头封存前后的信息缺口、团队互信等 |

差异化最低要求：相邻两份档案不得在“水域类型 + 现实问题 + 异常表现 + 高潮选择”四项中有三项相同。

## 七、档案连续性规则

每份档案结束时必须产生至少一种接力：

1. **证据接力**：本档案获得的材料在后续被重新解释。
2. **人物接力**：本档案出现的委托人、目击者、对手或被救者再次影响主线。
3. **地点接力**：水系、旧河道、迁徙路线或历史记录把两处水域连起来。
4. **后果接力**：主角的选择改变团队关系、公众舆论、对手行动或下一处水域状态。

禁止连续性假象：不能只在结尾摆出一个新地点名称，下一档便完全丢弃前档后果。

回声档案还必须满足：明确指出回声来源档案、旧信息、当前新证据、旧解释、修正后的解释和继续保留的疑点。汇流档案还必须满足：至少汇总三份本卷档案与一份前卷档案的证据。

## 八、六条全书长线

| 长线 | 核心问题 | 早期表现 | 中期升级 | 后期回收方向 |
|---|---|---|---|---|
| 万水竿线 | 它究竟在寻找什么 | 感知异常但不解释 | 反应规律与旧档案重合 | 揭示其真实职责与代价 |
| 老莽头线 | 他是谁，为何此前沉默 | 档案001复合条件解除封存后首次开口，只说半截规则 | 逐步确认东北地域印记，并发现他也不知道旧货市场以前的完整来历 | 解释封存、江流时期状态与最终选择，保留万水竿最早源头之谜 |
| 江流线 | 江流为何忽视预警、为何选择分流并为救老高牺牲 | 水纹、旧竿痕、断桥水库记录、橄榄绿救援影像 | 老高三段记忆与旧档案互相校正 | 重构工作忙碌、信号混淆、主动纠错、军民救援和个人牺牲，证明死亡不是异常献祭 |
| 摄像机线 | 为什么镜头能拍到第二层信息 | 画面边缘异常、缺帧 | 林溪旧素材出现同源现象 | 揭示影像、观察者与异常水域的关系 |
| 百档案线 | 为什么团队要建立100份记录 | 看似独立的水域事件 | 现水、回声与汇流档案逐渐形成关系图 | 百档案还原主回流被分散后的完整路径 |
| 逆流者线 | 谁在利用异常 | 个别抢拍、转运和违规线索 | 形成持续追踪异常的组织或利益链 | 与老姚争夺异常水域的解释权和处置权 |

六条长线不能等量推进。每卷重点推进两条、辅助推进两条、静置两条，避免每档都重复提醒全部谜团。

## 九、伏笔五阶段

长线伏笔统一采用：

1. **埋设**：以可见物、异常动作或信息缺口出现，不解释意义。
2. **误读**：人物依据当时知识给出合理但不完整的解释。
3. **部分回收**：后续证据证明早期判断只对一半。
4. **反转**：旧证据获得相反或更深的含义。
5. **最终回收**：真相改变人物选择，而不只是解释设定。

示例草案：

`档案001水纹` → `档案006确认六处同源` → `档案020误认为万水竿留下标记` → `档案050发现水纹早于万水竿` → `档案090确认水纹是水域网络的交流或警告方式`。

具体档案编号属于规划草案，需随十卷卷级答案和卷纲一起复核。

## 十、网文章节映射原则

- “档案”是一个完整调查事件，不默认等于一章。
- 每份档案应包含进入、误判、调查、反转、选择、余波等多个章节功能。
- 档案长短允许变化，卷首、卷末和跨档案事件可以更长，避免100份档案机械等长。
- 每章必须完成信息、行动、关系或风险中的至少一项推进。
- 每份档案结尾提供局部回报；每卷结尾提供阶段真相；全书长线保留更大的未解问题。
- 具体每档章节数和全书字数在平台定位、更新节奏和世界真相确定后另行确认。

## 十一、关键状态变化

每份档案至少改变一项状态：

- 人物知道了什么。
- 人物相信了什么或不再相信什么。
- 团队关系增加或失去多少信任。
- 万水竿、摄像机或证据处于什么状态。
- 某处水域被保护、公开、封存、破坏或继续失控。
- 对手获得或失去什么。
- 下一档案为什么必须发生。

未产生状态变化的事件只能作为章节素材，不能单独占用一份正式档案编号。
