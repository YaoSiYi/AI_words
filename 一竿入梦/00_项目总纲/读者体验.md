# 读者体验

## 核心体验

- 体验关键词：钓鱼日常、空军、伪纪录片、异常水域、证据链、万水竿、老莽头、真实钓技、装备实验、生态敬畏。
- 情绪曲线：真实空军开局 -> 发现异常证据 -> 第一次专业判断 -> 判断只对一半 -> 万水竿有限提示 -> 二次判断破局 -> 获得证据 -> 更深谜团。
- 爽点：不是“必上大鱼”，而是老姚从错误判断中修正，用真实钓技和现场证据逼近异常真相。
- 悬念点：万水竿来历、摄像机为何能拍到异常、老高旧事、林溪旧素材、怪鱼是否也在观察老姚。

## 短视频观看动力

每集同时利用五种动力：

1. 信息缺口：知道异常，但不知道原因。
2. 预测欲：给出足够线索，让观众能猜。
3. 未完成效应：建立具体目标、限制和失败代价。
4. 认知修正：观众与主角的第一个答案只对一半。
5. 能力成长：老姚、万水竿和调查团队逐步接近真相。

## 每集四层价值

| 价值 | 服务人群 | 表现方式 |
|---|---|---|
| 情绪价值 | 泛娱乐观众 | 危险、压迫、未知、反转 |
| 知识价值 | 钓友与新手 | 一个可验证的鱼情知识 |
| 社交价值 | 评论用户 | 有依据的专业选择或证据争议 |
| 连续价值 | 追更用户 | 万水竿、旧素材和上一任持竿人线索 |

每集硬性要求：

> 一个视觉爆点 + 一个真实知识点 + 一个判断争议点 + 一个世界观线索。

## 节奏注意事项

- 禁止前55秒只吊胃口、最后5秒才给答案。
- 采用“小满足连续支付 + 大答案适度延迟”。
- 每6-12秒必须发生信息、判断、情绪或视觉变化。
- 章节和视频钩子必须来自已出现证据，禁止无依据突然反转。
