# Gofishing PRD 转译笔记

记录日期：2026-06-27
目标项目：一竿入梦
研究问题：如何将 Gofishing 项目中的 AI 钓鱼闯关短剧 PRD 转译为中长篇小说项目资料。
标签：外部参考、系统闯关、钓鱼、怪鱼、轻喜剧、待确认设定

## 结论摘要

Gofishing PRD 的核心模式非常适合转译为中长篇小说：现实夜钓空军提供人物起点，系统绑定提供类型文钩子，万水竿提供可持续规则约束，全球怪鱼100关提供长线结构。小说化时应弱化短视频生产模块，强化人物成长、关卡因果、现实与梦境的互相影响。

## 证据

- PRD 明确提出核心模式：夜钓入梦、系统绑定、万水竿、全球怪鱼100关。
- PRD 将内容拆成三线：主线闯关、钓鱼知识复盘、现实夜钓喜剧线。
- PRD 规定系统不是外挂，只能有限提示水温、水层、鱼线承压、鱼类习性和危险临近。
- PRD 给出第一季 MVP 节点：夜钓入梦、亚马逊黑水河巨骨舌鱼、沼泽禁区鳄雀鳝、雷暴水域电鳗、湄公河深潭巨鲶、现实醒来仍空军。

## 推断

- 小说主线可以从“挑战怪鱼”升级为“理解水域规则和系统真实目的”。
- 主角不宜设定为天才钓手，保留空军、嘴硬、误判和翻车，反而更适合长篇成长。
- 系统限制是本项目的关键。如果系统太强，钓鱼判断和人物成长都会失效。
- 第一卷可以先借用 PRD 的 6 个 MVP 节点，但需要扩展为 20-30 章结构。

## 小说可用素材

- 书名方向：《一竿入梦：全球怪鱼100关》。
- 第一卷名：《空军者的试炼》。
- 宣传语方向：一个连续空军的钓鱼佬，误入全球怪鱼闯关系统。
- 核心道具：万水竿。
- 核心系统：全球怪鱼闯关系统。
- 主角声音：嘴硬、接地气、带河南方言味，关键时刻认真。
- 每关结构：水域、目标鱼、限制、误判、提示、调整、高潮、结果、钩子。

## 不确定点

- 主角姓名、年龄、职业和现实关系网未定。
- 系统来源未定：鱼神、梦境、生态试炼、未知文明或其他机制均可。
- 100关是否全部展开未定。
- 第一卷是否完全采用 PRD 中的鱼种顺序未定。

## 风险与避坑

- 不要把小说写成短视频脚本合集。
- 不要把系统写成万能外挂。
- 不要把珍稀鱼类、保护鱼类写成炫耀捕杀对象。
- 不要让钓鱼术语压过剧情，需要用冲突和选择承载知识点。

## 可入设定候选

- 主角从现实夜钓连续空军开始。
- 入梦触发物为浮漂异常发光和水面旋涡。
- 万水竿每关最多三次提示。
- 每关必须有一次主角误判和一次临场调整。
- 第一卷末现实醒来，鱼护仍空，但留下梦境痕迹。
