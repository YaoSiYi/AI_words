# 《一竿入梦》信息差总控优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变V2.1世界观、十卷答案阶梯和第一卷既定剧情的前提下，建立可执行的信息差管理体系。

**Architecture:** 新增一份独立的全书信息差总控表，负责管理读者、老姚及主要角色之间的知识边界；全书大纲只登记机制与引用；第一卷章纲细化到档案和关键章节的信息转移；状态快照登记本次优化为后续正文生产规则。

**Tech Stack:** Markdown小说项目文档、现有V2.1十卷卷纲与32章章纲。

---

### Task 1: 建立全书信息差总控表

**Files:**
- Create: `一竿入梦/03_剧情结构/全书信息差总控表_V2.1.md`

- [x] **Step 1: 定义四类信息状态**

写明“读者领先、主角领先、共同未知、同证异解”的用途、使用边界和公平性要求，并区分作者正史与读者已知。

- [x] **Step 2: 建立角色知识边界**

登记老姚、林溪、老高、老莽头、摄制组与读者在开篇时分别知道、误解和隐瞒的内容。

- [x] **Step 3: 建立十卷信息差阶梯**

逐卷明确读者领先项、老姚领先项、共同未知、同证异解以及卷末知识转移，确保信息差服务现有卷级答案。

- [x] **Step 4: 建立使用规则**

规定每档案只选择最有效的信息差，不强制四类齐全；每次揭示必须改变行动、关系或判断；禁止依靠视角作弊。
