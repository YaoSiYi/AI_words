# 第001章：无声湖没有声音

凌晨一点多，老姚第三次把保温杯拧开，又原样拧了回去。

杯里的茶早凉透了，浮着两片泡开的茶叶梗。喝吧，苦得舌根发木；倒了吧，又觉得这一晚上已经够赔本，连口茶都浪费不起。

他把杯子塞回钓箱底下，顺手摸了摸裤兜。

烟盒是瘪的。

“中。”老姚冲水面点点头，“鱼不吃，烟没有，茶也凉。恁这地方待客挺周到。”

脚边的小黄抬了一下眼皮，鼻尖挨着前爪，没打算搭理他。

十来米外，摄像机还亮着一个小红点。扛机器的小伙在折叠凳上坐得腰都塌了，隔一会儿抬头看一眼老姚，再看一眼水面。后来连叹气都没声了，只剩两根手指在膝盖上轮流敲。

老姚假装没看见。

他在断桥水库坐了三个多小时，鱼护空得能装风，浮漂却一直稳稳露着三目半。水面并不死，窝点外沿偶尔还有细泡顶上来，芝麻粒大小，冒两三个就散。看着像有鱼，偏偏钩饵下去以后，连小杂鱼试口的抖动都没有。

这种鱼情最折磨人。

真没鱼，收竿也就收了。水里明明有动静，它又不肯给一口，钓鱼人坐在岸上，总觉得下一竿能把前面三个小时全捞回来。

“再等十分钟。”老姚说。

后面没人接话。

他回头看了一眼：“拍着没？”

扛机器的小伙朝他比了个手势，意思是一直开着。

“拍着就中。省得回头有人说俺找借口。”

老姚低下头，把钩上的饵捏掉。饵在水里泡得发白，搓在指肚上没什么黏性。他重新开了一小团，水没敢多加，拢好后塞进饵盆角落醒着，又把浮漂往上推了半目。

嘴上可以赖鱼，手上的步骤不能赖。他把饵、钩底和轻微走水挨个过了一遍，没找出哪处偷了懒。

老姚重新上饵，扬竿抛了出去。

铅坠落在原窝右侧，声音很轻。浮漂躺在水面上，慢慢翻身，往下一沉，最后又停在三目半。

“漂亮。”

他照例夸了一句。

小黄换了个方向趴着，把屁股冲给他。

“你懂啥。漂站得稳，说明俺调得准。”

小黄尾巴在泥地上扫了一下，带起几粒干土。

水库西北这片湾子三面被土坡和乱树围着，岸边还留着半截废弃水泥台。白天从高处看，就是断桥水库边上一块不起眼的静水。跟拍的人为了不把具体钓位露出去，来前在记录板上写了个代号：无声湖。

老姚当时还笑，说名字起大了，水面加起来还没村口麦场宽。

现在坐到夜里，他慢慢笑不出来了。

太静。

水库夜里本不该这么静。远处总该有青蛙叫，芦苇根下也少不了小鱼拱水。风从库面绕进湾子，草叶互相刮着，时不时还会发出一阵细碎的响。

今晚这些声音都有过。

只是越来越少。

老姚刚来的时候，土坡后面还有虫叫。十一点左右，近岸炸过两次小鱼。等到十二点半，水面偶尔还能听见一声轻响。现在只剩设备散热的小风扇转着，嗡声细得发虚。

小黄忽然把脑袋抬了起来。

老姚跟着看向水面。

浮漂还是三目半。

“有东西？”

小黄没有往前凑，反而从钓箱旁站起来，鼻子朝着左边那片芦苇抽了两下。它平时听见鱼打水，恨不得把前爪踩进泥里。今晚只看了一会儿，便往老姚腿后退了半步。

老姚伸手在它背上顺了一下。

狗毛有点潮，后颈却绷得紧。

“别吓唬自己。”他也不知道这话是说给谁听的，“一晚上没口，狗都跟着心虚。”

话说完，他端起竿子，试了试线组。

钩饵还在水下，浮漂没有下顿，也没有上顶。竿尖传回来的重量和平时差不多，没挂草，更不像中鱼。

老姚把竿放回架上，手没有立刻松开。

水面上，那截原本贴着水皮的风线轻轻动了一下。

起初他以为是风。

可岸边的芦苇没动，头灯挂带上垂下来的线头也没动。只有竿尖到浮漂之间那一段线，从中间慢慢拱起来，拉出一道很浅的弧。

浮漂仍在原位。

老姚盯了几秒，伸手把头灯压低。白光贴着水面扫过去，线弧清清楚楚，正一点点朝左侧芦苇靠。

后面的折叠凳响了一声。扛机器的小伙已经站起来，没问话，只把摄像机重新架稳。

老姚的嘴唇动了动。

他本来想说轻微走水，话到嘴边，又咽了回去。水流真能带线，浮漂不可能钉在原处一点反应都没有。

他把食指搭在竿身上，没有扬竿，只往下压了压竿尖。

那道线弧没有松。

反而又朝岸边挪了两寸。

小黄贴着他的裤腿，喉咙里滚出一声很低的呜鸣。

老姚坐直了。

空鱼护还搭在水边，水沿着护口轻轻一贴，它便慢吞吞晃了回来。这回老姚没心思踢它，只盯着那枚一动不动的浮漂，又慢慢把目光移到横着走的风线上。

三目半。

还是三目半。

那道线弧却正一寸一寸地往左边芦苇根下钻。
