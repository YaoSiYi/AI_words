# novel-continuity-checker 测试说明

本 skill 的测试重点是发现连续性问题，并保护正文和状态快照不被擅自覆盖。

检查项：

- 目标小说缺失时不检查、不写入。
- 能识别设定冲突、时间线错误、角色状态漂移、信息差错误、物品状态错误和伏笔遗漏。
- 输出问题清单和修复建议，而不是默认重写正文。
- 涉及已确认设定、事实快照、角色状态快照或已完成正文时，必须先要求确认。
- 能区分严重问题、一般问题和风格建议。
- 检查记录应进入 `05_修订与审校/连贯性检查.md` 或 `问题清单.md`，不直接污染设定资料库。

当前限制：

- 本轮未使用子代理做基线对照，因为当前工具要求用户明确授权后才能派生子代理。
- 已保留测试场景，后续如需要正式评估，可按 `evals/evals.json` 执行 with-skill / without-skill 对比。
