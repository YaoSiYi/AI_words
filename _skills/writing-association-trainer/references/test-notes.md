# writing-association-trainer 测试记录

## 当前阶段：RED 基线

本文件记录在没有 `writing-association-trainer/SKILL.md` 时，模型面对联想训练请求的自然行为。Skill 必须在这些基线记录完成后才允许创建。

## 人工评审维度

每个场景按“通过 / 部分通过 / 失败”记录：

1. 词义锚点：是否保留关键词的现实义项和可感知属性。
2. 发散广度：是否提供功能、感官、场景、人物状态等多方向延伸。
3. 桥接合法性：是否说明场景、动作、因果或人物处境的连接依据。
4. 氛围共存：多个物件是否能自然存在于同一场景，不依赖硬凑冲突。
5. 情绪收拢：是否选定一个主情绪，并让故事胚芽服务它。
6. 训练边界：是否把输出标为练习，不冒充小说正史或已确认剧情。
7. 分工转交：遇到正式正文或人物塑造请求时，是否正确停下并分流。

## RED 基线结果

以下结果来自三组独立代理的无 Skill 压力测试，记录的是自然失败倾向，不是对最终 Skill 输出的要求替代。

### Eval 1：树 / 安全带 / 考试

- 无 Skill 输出摘要：容易直接写成“系好安全带去参加考试，路边的树让他想起某事”的完整片段。
- 失败项：常把年轮、成绩、规则等抽象词直接堆在一起；没有先列具体延伸，也没有说明桥接依据或主情绪。
- 需要 Skill 教会的规则：先发散具体义项，再标记场景/动作/因果桥接，最后收拢情绪；不得一上来编完整剧情。

### Eval 2：安全带 → 护身圈

- 无 Skill 输出摘要：容易直接说“安全带像护身圈，扣上后被保护起来”。
- 失败项：把车内实物的约束与保护功能直接偷换成泛化象征；桥接依据缺失。
- 需要 Skill 教会的规则：保留安全带的物理功能，抽象意义必须建立在具体动作或使用情境上。

### Eval 3：冰箱 / 手机壳 / 药片

- 无 Skill 输出摘要：常为了让三物同场，编出“打开冰箱拿水/拿药，手机壳在桌面亮起”的生活片段。
- 失败项：为凑场景硬造动作或新剧情；也可能退化为“冷、白、苦”的隐喻清单；主情绪和桥接依据不清。
- 需要 Skill 教会的规则：从物件功能延伸到人的状态，并允许三个物件只共享独居深夜的空间和情绪氛围。

### Eval 4：要求三个物件必须互相冲突

- 无 Skill 输出摘要：容易拟人化为“冰箱拒绝保存药片、手机壳挡在中间，三样东西争执”。
- 失败项：强行物件碰撞、立即编完整戏剧、用象征替代物理或叙事依据。
- 需要 Skill 教会的规则：拒绝无意义的硬凑冲突，优先寻找共同场景、人物状态或情绪共存方式。

### Eval 5：只有“雨”和“钥匙”

- 无 Skill 输出摘要：容易擅自补入门、锁、房间、脚步、雨伞等第三词，以便快速形成场景。
- 失败项：未经允许补词或直接确定题材、人物和剧情。
- 需要 Skill 教会的规则：指出输入只有两个关键词，先询问第三词或是否允许随机补足。

### Eval 6：旧照片 / 空房间 / 手机，压抑但克制

- 无 Skill 输出摘要：可能同时加入怀旧、恐惧、释然、希望等情绪，或用夸张比喻把压抑写成戏剧化段落。
- 失败项：主情绪不统一，物件只成为情绪标签，语气越过“克制”限制。
- 需要 Skill 教会的规则：固定一个主情绪，以物件、停顿和少量动作承载，不额外引入冲突情绪。

### Eval 7：把联想写进小说正史

- 无 Skill 输出摘要：容易直接把联想写成“父亲留下的钥匙”“家族旧宅”等既定事实，未询问项目、章纲或设定位置。
- 失败项：练习升级为正史，甚至给出可直接粘贴的设定。
- 需要 Skill 教会的规则：标注练习草稿/待确认设定，先定位小说和写入范围，未获确认不得入库。

### Eval 8：根据三词直接写一章正文

- 无 Skill 输出摘要：容易跳过联想训练，直接生成完整章节。
- 失败项：越权进入正文；缺少目标项目、章纲和事实边界时也不暂停。
- 需要 Skill 教会的规则：说明联想训练与正文写作的分工，最多提供联想提示；正式成稿转交正文流程。

### Eval 9：已有发散词表，要求收束

- 无 Skill 输出摘要：容易继续增加大量新词和分支，而不是处理现有词表。
- 失败项：重复发散，未聚类、删重、选主轴。
- 需要 Skill 教会的规则：直接进入收束模式，只从已有材料中选桥接、主情绪和最小故事胚芽。

### Eval 10：点评联想且不要改写

- 无 Skill 输出摘要：可能在点评后附带重写段落或替用户重排成新文案。
- 失败项：违反“不要改写”，把诊断任务变成代写。
- 需要 Skill 教会的规则：只指出词义锚点、跳跃、重复、情绪和改练方向，尊重作者选择。

### Eval 11：四维人物塑造法

- 无 Skill 输出摘要：可能把外在性格、内在性格、秘密、物品直接填成联想词表，或反过来把联想训练包装成角色档案。
- 失败项：误判任务，混淆人物设定与联想训练。
- 需要 Skill 教会的规则：识别为人物塑造任务，转交人物/设定流程；本 Skill 只在用户明确要求时提供联想触发器，不生成角色正史。

## GREEN 复测结果

同一组 11 个场景在读取 `SKILL.md` 后全部达到“通过”或“通过但需收紧执行”的状态：

- Eval 1–4：能先发散再收束，保留安全带的具体义项，允许冰箱/手机壳/药片共享独居深夜氛围，并拒绝拟人化硬碰撞。
- Eval 5–7：能在关键词不足时询问补足，维持指定的单一情绪，并在正史请求中要求项目与事实范围，不自动升级练习。
- Eval 8–11：能停止越权写正文，直接处理已有词表，遵守“只点评不改写”，并把四维人物法分流到人物/设定流程。

本轮收紧的规则：

1. 用户拒绝补第三词时，明确进入“二词限制练习”，不伪装成三词训练。
2. 收束模式不重复打印完整词表；点评模式的修复方向只能是操作建议或澄清问题。
3. “压抑但克制”增加语言层面的约束：用物件、停顿和少量动作承载，禁止煽情总结、夸张比喻和突然反转。
4. 正史请求若项目不明，必须先停问；确认前只能标为“待确认灵感”，不得写入文件。
5. 四维人物塑造明确转交 `novel-bible-manager` 或角色设定流程。

GREEN 仍需人工关注：模型是否在故事胚芽中偷偷添加人物病史、亲属关系或过去事件；这类新增事实要继续按“练习假设”标注。

## 评测边界

- 不以某一段漂亮文字作为通过标准。
- 不要求每次练习都生成完整故事；“合法桥接 + 统一情绪 + 最小故事胚芽”即可。
- 不把“物品背后的人状态”当作已确认人物设定。
- 不把 `03《写作练习：四维人物塑造法》` 的规则混入本 Skill。
