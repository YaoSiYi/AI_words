# 联想训练 Skill

## 作用

把互不相关的词训练成可用的写作材料：先扩大联想，再寻找成立的桥接，最后用一个主情绪收拢成画面或故事胚芽。训练结果是练习草稿，不是小说正史。

联想广度决定素材池的大小，但联想的价值不在于词越怪越好，而在于能否保留具体词义，并让物件、场景和人的状态彼此解释。

## 触发后先判断模式

- **发散模式**：只有关键词，或用户要求随机词练习。默认使用三个词；少于三个时先询问是否补词。用户拒绝补足时，可以明确标注“二词限制练习”，只围绕现有词做桥接，不假装它拥有三词训练的广度。
- **收束模式**：用户已有发散词表，要求串成画面、情绪或故事胚芽。不要重复发散，也不要机械重新打印整份词表。
- **点评模式**：用户要求点评自己的联想。只诊断词义、桥接、情绪和逻辑，不替用户改写；修复方向只写操作建议或提问，不写示范段落。
- **正文转交模式**：用户要求章节、场景正文或写入小说项目。先停下，不生成长篇故事胚芽；确认目标项目和事实范围后转交 `novel-draft-writer` / `novel-prose-craft-keeper`。
- **任务分流**：用户要求用“外在性格、内在性格、隐藏秘密、标志性物品”构建角色时，这是四维人物塑造，应转交 `novel-bible-manager` 或角色设定流程，不要冒充联想训练。

## 核心流程

### 1. 发散：保留具体锚点

对每个词分别给出多方向延伸，至少覆盖其中几类：

- 现实功能和使用动作
- 触感、声音、温度、颜色等感官
- 可进入的地点、时段和生活场景
- 人物状态：等待、独居、压力、秘密、忍耐等
- 可承载的情绪，但不要把情绪词当成物件本身的唯一含义

先列材料，不急着编完整故事。具体物件的现实义项必须保留。例如“安全带”首先是车内用于约束和保护的护带，不能直接偷换成任意“保护圈”。

### 2. 关联：说明桥接为何成立

优先寻找以下桥接：

1. 同一场景或共享氛围
2. 可见动作、物件使用或空间关系
3. 人物状态、目标或因果关系
4. 情绪或主题上的呼应

每条桥接都要回答：三个词如何进入同一个空间或人的处境？为什么不是硬凑？后一层抽象关系不能替代前面的具体锚点。

多个物件不必互相碰撞。像冰箱、手机壳、药片可以共同存在于独居深夜，靠空荡、低鸣、秘密和失眠形成同一氛围；除非用户明确要求，否则不要把物件拟人化后强行争执。

### 3. 检查：拦截四类风险

- **词义偷换**：实物被无依据改成抽象象征。
- **空泛隐喻**：只说“都代表成长/束缚/希望”，没有动作、空间或使用依据。
- **强行碰撞**：为了让词发生戏剧冲突而制造不自然事件。
- **情绪串味**：用户指定“压抑但克制”时，不要同时塞入热烈、治愈、恐怖等相反基调。

发现风险时先指出断点，再给一个可执行的操作建议（例如“补一个可见动作”“改为同一地点”“删去第二情绪”）或一个澄清问题，不要写新的示范段落来掩盖问题。

### 4. 收拢：一个主桥接，一个主情绪

从成立的关联中选一条主桥接和一个主情绪，把材料压缩成：

- 一个共享场景；
- 一条人物动作或处境线；
- 一段最小故事胚芽或下一轮练习提示。

默认不扩写成完整小说段落，更不生成章节。故事胚芽只表达练习方向，不新增未获用户确认的小说事实。收束模式只输出选中的桥接和结果，点评模式只输出诊断与改练建议。

## 默认输出格式

```text
训练状态：练习草稿 / 需要补充输入 / 转交正文流程 / 任务分流
关键词锚点：每个词的具体义项和延伸方向
合法桥接：桥接类型、连接链、为什么成立
风险检查：词义偷换、空泛隐喻、强行碰撞、情绪冲突、因果缺口
情绪收拢：主情绪、共享场景、最小故事胚芽
下一轮练习：一个可执行的限制或替换词
```

点评模式可以只输出“问题定位 + 保留建议 + 下一轮改练”，不要附带重写稿。收束模式应直接处理用户已有词表，不重新罗列同义词。

## 正史与文件边界

- 所有联想、人物状态和故事胚芽都标为练习草稿或待确认灵感。
- 不自动写入小说项目、设定库、章纲、正文、状态快照或资料索引。
- 用户说“写进正史”时，如果目标小说不明，先停下询问项目；随后再询问写入位置、哪些内容已确认，以及是否采纳。未完成确认前，只能把内容称为“待确认灵感”，不得写入任何文件或升级为事实。
- 用户要求正式正文时，说明联想训练已完成的部分，转交正文 Skill；不要在本 Skill 内继续生成章节。

## 质量底线

一次合格训练不要求故事复杂或句子华丽，但必须做到：

- 具体词义没有被偷换；
- 联想不是孤立词表，而有可解释的桥接；
- 多个物件能在同一场景或氛围中自然共存；
- 最终有一个主情绪；若指定“压抑但克制”，用具体物件、停顿和少量动作承载，不用煽情总结、夸张比喻或突然的希望/恐惧反转；
- 输出没有冒充正史，也没有越权代写正文或角色设定。
