# novel-workspace-router 测试说明

本 skill 的测试重点不是文学质量，而是路由正确性。

检查项：

- 是否区分工作区级任务和单本小说任务。
- 是否在目标小说缺失时停止写正文。
- 是否防止把具体小说内容写入 `_agent/`。
- 是否把外部资料放入参考区，而不是正式设定。
- 是否在核心设定或已有正文可能被改动前要求确认。

当前限制：

- 本轮未使用子代理做基线对照，因为当前工具要求用户明确授权后才能派生子代理。
- 已保留测试场景，后续如需要正式评估，可按 `evals/evals.json` 执行 with-skill / without-skill 对比。
