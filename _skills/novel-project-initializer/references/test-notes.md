# novel-project-initializer 测试说明

本 skill 的测试重点是安全初始化，而不是文学内容质量。

检查项：

- 项目名缺失时不创建目录。
- 项目名包含 `../`、路径分隔符或明显越界意图时不创建目录。
- 同名目录存在时不覆盖。
- 能复制 `_templates/novel-project-template/` 的完整结构。
- 只写入用户已提供并明确确认的信息。
- 灵感、可能性和未确认素材不得进入 `06_状态快照/已确认设定.md`。
- 输出创建报告，说明创建位置、写入文件和待补充内容。

当前限制：

- 本轮未使用子代理做基线对照，因为当前工具要求用户明确授权后才能派生子代理。
- 已保留测试场景，后续如需要正式评估，可按 `evals/evals.json` 执行 with-skill / without-skill 对比。
