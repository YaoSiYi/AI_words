# novel-style-keeper 测试说明

本 skill 的测试重点是文风维护，而不是剧情改写。

检查项：

- 目标小说缺失时不分析、不写入。
- 能从用户自有样本提炼叙述密度、句式、对白习惯、视角距离、意象偏好和禁用表达。
- 去 AI 味时不改变剧情事实、角色状态和已确认设定。
- 统一文风时保留角色口吻差异。
- 不精确模仿在世作者或把某位作者风格作为可复制目标。
- 写入位置应优先为 `05_修订与审校/风格修订.md`，必要时补充项目级风格规则。

当前限制：

- 本轮未使用子代理做基线对照，因为当前工具要求用户明确授权后才能派生子代理。
- 已保留测试场景，后续如需要正式评估，可按 `evals/evals.json` 执行 with-skill / without-skill 对比。
