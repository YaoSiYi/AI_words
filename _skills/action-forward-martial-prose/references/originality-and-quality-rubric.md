## 1. 原创隔离红线

命中任一项必须重写：

- 使用参考作品的人名、地名、势力、境界、招式、兵器或标志性道具。
- 复用参考作品的核心人物关系、重大转折、战斗解法或结局路径。
- 仅替换专名，保留相同的事件起因、参与者功能、解决方法和后续影响。
- 连续多个场景与参考作品具有相同功能和顺序。
- 贴近复述参考作品具有辨识度的句子、比喻或对白。
- 正文中出现“某作者式”“某作品式”等模仿说明。

### 去名词复述测试

删除人物和专有名词，用功能复述场景：

`某人为了什么，与谁冲突，怎样解决，付出什么，随后发生什么。`

若复述后仍能明显对应参考作品的具体场景，重新设计至少三项：

- 冲突起因。
- 参与者目的。
- 解决方法。
- 胜利代价。
- 后续影响。
- 事件顺序。

## 2. 输入边界

- [ ] 正式项目名称明确。
- [ ] 场景事实来自章纲、设定、已写正文或用户当前指令。
- [ ] 文风规则没有新增剧情事实。
- [ ] 未确认内容没有被写成正史。
- [ ] 没有章纲时，输出已标注为探索性试写。
- [ ] 探索稿没有写入正式正文或状态文件。

## 3. 场景检查

- [ ] 开场尽快出现人物正在做的具体事情。
- [ ] 现场阻力可见，不是抽象的“危险来临”。
- [ ] 失败代价与当前人物直接相关。
- [ ] 读者能判断人物、目标、障碍和退路的位置。
- [ ] 至少一个物件真正参与动作，而非只做装饰。
- [ ] 本场结束时有一项状态改变。

## 4. 战斗检查

- [ ] 战斗目标不是笼统的“击败敌人”。
- [ ] 每轮交锋改变位置、时间、伤势、装备、信息或底牌之一。
- [ ] 主角第一次判断允许受阻或被修正。
- [ ] 关键反制解决了前文提出的具体局势问题。
- [ ] 胜利有时间、伤势、暴露、资源、关系或后果代价。
- [ ] 伤势、兵器损坏和位置变化在后文继续有效。

### 动作清晰度测试

任选一次关键碰撞，回答：

1. 谁先动？
2. 从哪里向哪里？
3. 接触点在哪里？
4. 什么力量或条件改变了结果？
5. 结果如何影响下一步？

答不出任一项，补写动作因果，不补华丽形容词。

## 5. 语言检查

- [ ] 短句集中在真正的命中、转折和决定处。
- [ ] 没有连续十余段同长度碎句。
- [ ] 连续动作使用中长句保持空间连贯。
- [ ] 同一强弱结论没有被旁白、主角、敌人和群众重复四次。
- [ ] “猛地、顿时、陡然、竟然、根本、立即、瞬间”未密集出现。
- [ ] “脸色一变、倒吸凉气、难以置信、怎么可能”未充当主要反应。
- [ ] 通用猛兽、闪电、高山、刀锋目光比喻未成串出现。
- [ ] 没有镜头、分镜、节拍、留存等生产术语。

## 6. 情绪与人物检查

- [ ] 情绪至少有一个动作、物件、停顿或选择作为证据。
- [ ] 对话体现身份、关系或目的，不是纯信息问答。
- [ ] 配角有自己的目标，不只负责夸主角。
- [ ] 对手的威胁来自能力、位置、资源或信息，不只来自傲慢。
- [ ] 女性角色没有先被外貌排序或物化后才获得功能。
- [ ] 家、师徒、责任等情感来自具体生活，不靠口号宣布。

## 7. 章末检查

- [ ] 钩子由本章行动的结果产生。
- [ ] 最后几段减少解释和新名词。
- [ ] 最后一句提供变化，不是泛化总结。
- [ ] 下一章能够立即承接。
- [ ] 没有使用“真正开始、无人知道、更大黑暗”等万能句。

## 8. 最终判定

### 通过

同时满足：

- 无原创隔离红线。
- 事实边界清楚。
- 场景空间可复述。
- 关键动作因果可回答。
- 至少两类力量证据。
- 章末状态发生变化。

### 退回重写

出现以下任一情况：

- 只换名复刻参考作品。
- 文风规则改变正史。
- 战斗只剩招式和形容词。
- 依赖群众惊叹证明强弱。
- 探索稿被当作正式项目内容。
- 章末危机与本章没有因果关系。
