# novel-plot-architect 测试说明

本 skill 的测试重点是剧情结构设计和边界控制。

检查项：

- 目标小说缺失时不设计、不写入。
- 不把章纲、卷纲扩写成正文。
- 根据已确认设定、待确认设定和状态快照区分事实与假设。
- 与已确认结局、核心设定或已写正文冲突时先提示，不覆盖。
- 能维护全书大纲、卷纲、章纲、冲突链、伏笔表和时间线。
- 伏笔计划不得自动写成已发生事实。
- 输出结构更新报告和待确认问题。

当前限制：

- 本轮未使用子代理做基线对照，因为当前工具要求用户明确授权后才能派生子代理。
- 已保留测试场景，后续如需要正式评估，可按 `evals/evals.json` 执行 with-skill / without-skill 对比。
