# novel-prose-craft-keeper 测试说明

## 人工评审重点

本 Skill 的主要目标是主观阅读体验，不用单一自动分数代替用户判断。

试写时重点比较：

- 是否像小说，而不是故事基底或短剧脚本。
- 是否保留剧情事实，又明显增加生活感和人物呼吸。
- 画面是否能在读者脑中建立空间，而非只出现形容词。
- 情绪是否通过动作逐步变化。
- 摄像机是否退回现场物件的位置。
- 对白是否体现人物关系，而非采访问答。
- 是否减少连续碎句、模板对举、解释腔和万能钩子。

## 建议测试顺序

1. 先对《一竿入梦》V2.1第001章做独立重写，不覆盖原稿。
2. 用户对照V1、第001章V2.1旧稿和新试写稿，评价人味、画面、情绪、节奏与核心表达。
3. 根据反馈修改Skill规则。
4. 再测试一个非钓鱼题材场景，防止Skill只会复刻《一竿入梦》。

## 2026-08-03 白描增强失败基线

本轮按用户选择在当前任务内直接执行，因此先以现有 Skill 的指令覆盖度和既有测试作为 RED 基线，不把新增规则提前带入判断。

### 场景A：悬浮人物

- 原始表现：现有 Skill 会提醒补充物件、动作和空间关系，但没有定义白描，也没有要求说明这种技法在何种场景下能建立临场感、人物性格和行动因果。
- 缺失能力：可能把“增强画面”执行为增加若干现场细节，却不检查人物是否真正与空间发生作用，也不能稳定向用户解释白描的创作价值。

### 场景B：视点漂移与信息拥挤

- 原始表现：现有 Skill 只规定伪纪录片设备不能成为万能视角，没有通用的第一人称、第三人称有限和全知视角边界，也没有规定视点切换需要什么信号。
- 缺失能力：难以稳定识别无标记进入另一人物意识的视角泄漏；“段落随注意力变化”的规则也没有明确一个段落应先确定注意力中心。

### 场景C：过度白描

- 原始表现：现有 Skill 多次强调可见细节、可观察变化和减少作者总结，却没有明确说明“摄像机能否拍到”只能用于检查冗余解说。
- 过度执行风险：可能删掉决定人物选择的心理判断、记忆、必要概述、转场和自由间接叙述，把小说误写成动作清单或分镜脚本。

### 基线结论

- 已有能力：生活物件、基本空间关系、动作承接情绪、长短句变化、禁止机械碎句。
- 本轮必须新增：白描定义、使用场景、小说价值、通用视点控制、按症状加载规则，以及保护小说独有叙述能力的反机械化边界。

## 2026-08-03 白描增强绿色复核

本轮按用户选择采用当前任务内直接执行。复核时读取增强后的主 Skill，并分别只读取与症状对应的参考模块。

### 场景A：悬浮人物

复核片段：

> 陈默靠着办公室的门站了一会儿，才把椅子从桌下拖出来。坐下以后，他把写到一半的情况说明揉成一团，塞进最下面的抽屉。抽屉合上时卡了一下，他用膝盖顶住，直到锁舌咔哒一声扣紧。

结果：

- 通过人物、椅子、说明和抽屉建立可追踪空间，没有另造审查结果或文件去向。
- 疲惫、犹豫和隐瞒通过动作与物件新状态显现，白描的价值落在行动因果和情绪共创上。
- 没有额外罗列办公室陈设。

### 场景B：视点漂移与信息拥挤

复核片段：

> 林秋推门时，身后的脚步忽然停了。她没有回头，只从玻璃门的倒影里看见保安抬起对讲机。门合上以后，那道目光还黏在她背上。

结果：

- 删除了无标记进入保安内心的事实声明，改为林秋能感知的停步、倒影和目光。
- 保留林秋带压力的主观判断，没有把它伪装成全知答案。
- 信息围绕“身后的注意”这一中心展开，没有靠机械拆句处理拥挤。

### 场景C：过度白描

复核决定：

- 不接受“摄像机拍不到的一律删除”为绝对规则。
- 人物是否背叛朋友取决于内在判断时，保留必要心理、记忆或自由间接叙述；只删除已被行动重复证明的解释。
- 外部动作负责承接选择压力，不能替代全部思想过程，也不能把正文改成景别和动作清单。

### 绿色结论

- 三个基线缺口均已有明确规则和对应参考入口。
- 白描的使用场景、意义与小说价值已进入主 Skill，不再只散落在画面感条目中。
- 空间、视点、动作和呼吸可按症状独立加载，全面审校时也能组合使用。
- 反机械化边界覆盖心理、概述、转场、作者叙述、自由间接叙述、视点切换和碎句风险。
- 后续仍需用真实章节做用户主观验收；本轮只验证 Skill 结构与短场景执行逻辑。
