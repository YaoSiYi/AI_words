# 白描：视点控制

## 适用症状

遇到以下情况时读取本文件：

- 同一段落无提示进入多个人物内心。
- 第一人称写出叙述者无法感知、回忆或合理推断的信息。
- 第三人称有限视角忽然知道远处、背后或他人意识中的事实。
- 场景细节很多，却无法判断是谁在看、为什么注意到它。
- 用户要求检查视角、视点、POV、越界、跳镜头或代入感。

## 创作价值

稳定视点让读者知道信息从哪里来，也知道哪些信息暂时不可靠。它不仅保护画面连续，还能产生代入、悬念、误判和人物差异。

白描中的视点控制有四项价值：

- **信任：** 叙述遵守自己设定的信息边界。
- **代入：** 感官和注意力附着在具体经历者身上。
- **悬念：** 读者不能提前得到当前人物无法知道的答案。
- **塑造：** 人物注意什么、忽略什么，本身就是性格与处境。

## 当前观察者的信息边界

每个场景先确定主要视点承载者，再检查五类信息：

| 信息 | 可以写的条件 |
|---|---|
| 当下感官 | 在人物可见、可听、可触、可闻或身体可感范围内 |
| 内心活动 | 属于当前视点人物，或全知叙述已建立明确权限 |
| 既往知识 | 人物曾经知道、学习或经历过 |
| 推断判断 | 由眼前证据得出，并保留可能出错的余地 |
| 他人状态 | 通过动作、表情、语气和关系经验判断，不把推断冒充事实 |

视点越界的核心不是“摄像机拍不到”，而是叙述在没有信号的情况下取得了当前视点不应拥有的信息。

## 第一人称、第三人称有限与全知

### 第一人称

只直接确认“我”能感知、回忆、思考或合理推断的内容。“我”可以通过镜子看见自己的脸，可以感觉自己的姿势，也可以误读别人；这些都不构成跳出身体。

### 第三人称有限

叙述贴近一个人物，可以写他的感官、记忆、语言和内心。其他人的心理先表现为当前人物能够观察到的迹象，除非场景明确切换视点。

### 全知叙述

全知不等于随意跳头。它需要稳定的叙述声音、信息组织和切换秩序。即使叙述有权知道所有人的内心，也要判断此刻进入谁的意识能否增加意义，而不是只增加解释。

## 安全切换信号

需要更换视点时，优先使用：

- 新场景或明显的时间、地点转换。
- 空行、分节或章节边界。
- 清楚点明新的感知主体，并让后续细节持续服从他。
- 全知叙述中稳定、可辨认的叙述转向。

不要用一句话写甲的恐惧，下一句无提示揭示乙的真实想法，再立刻回到甲的身体感受。

## 短例：无信号越界与有限视点修订

越界版本：

> 林秋推门进屋，没有发现身后的保安已经认出了她。保安心想她就是嫌疑人。她觉得所有人都在盯着自己。

有限视点版本：

> 林秋推门时，身后的脚步停了。她没有回头，只从玻璃门的倒影里看见保安抬起了对讲机。门合上以后，那道目光还黏在她背上。

修订版不替保安确认心理事实，只保留林秋能获得的迹象和她带有压力的判断。

## 小说不是摄像机

“镜头”可以帮助检查位置和感知边界，但不能统治小说。以下内容有叙事价值时应保留：

- 当前人物的念头、记忆、联想和误判。
- 自由间接叙述中的人物语气与判断。
- 必要的背景概述、时间压缩和场景转场。
- 已建立全知权限后的作者叙述。

不要为了所谓纯画面，把人物内心删空；也不要把正文改写成景别、机位和剪辑指令。

## 检查问题

1. 当前场景主要由谁感知？
2. 每条关键信息来自感官、记忆、推断还是叙述权限？
3. 是否把人物的猜测写成了无误的客观事实？
4. 若进入另一人物意识，切换信号是否足够清楚？
5. 视点限制是否带来了悬念和人物差异，而不只是删减信息？
