# 《一竿入梦》正文技法配置

## 使用范围

目标项目为《一竿入梦》时读取。本配置控制正文质感，不改变V2.1世界观、卷纲、档案职责和角色正史。

## 样本优先级

1. V1正文提供生活感、叙述距离、老姚口吻和章节呼吸。
2. `05_修订与审校/风格修订.md`提供已确认的项目风格要求。
3. V2.1章纲、故事基底和设定文件提供当前剧情事实。
4. V2.1现有第001至004章只作失败案例，不得成为文风样本。

从V1继承文风，不继承系统闯关、固定入梦、任务面板和旧世界规则。

## 目标文风

以接地气的近距离第三人称讲述。叙述贴着老姚的注意力走，能看见他嘴硬、找台阶、犯嘀咕、被生活琐事打断，也能在真正危险时慢下来观察。

最终效果不是复刻V1，而是：

`V1的人味和生活细节 + 更清楚的空间动作 + 更连续的情绪递进 + V2.1的现实因果与核心表达`

## V1可继承技法

- 用蚊香、饵料盆、鱼护、钓友群、电三轮、凉茶等生活物件建立钓鱼现场。
- 笑点来自老姚的处境和面子，不靠旁白插段子。
- 小黄通过动作与老姚形成默契，不承担答案功能。
- 老姚先嘴硬，再用动作暴露心虚或认真。
- 允许章节在主线间短暂绕到生活细节，再自然回到异常。
- 结尾钩子从浮漂、竿身、鱼线、录音或旧物状态变化中生长。

## 需要升级的V1问题

- 纠正语病、标点混乱和无必要的重复。
- 控制夸张网络口头语，不让喜剧破坏悬疑。
- 增强动作和空间连续性，避免只靠形容词制造异常。
- 情绪不要只靠喊叫和吐槽，要让停顿、误判、手上动作和选择共同推进。
- 方言点到为止，保持驻马店口吻但保证阅读流畅。
- 每章保持完整小弧线，不因追求钩子强行拆短。

## V2.1必须保留

- 异常从真实鱼情、水文、生态和器材问题中生长。
- 万水竿只有限提示，不能自动解题、定位或上鱼。
- 老莽头说话克制，不成为任务发布器和百科全书。
- 摄像机和录音是有限证据，不是万能视角。
- 核心表达通过老姚的选择和代价落地。
- 生态保护与现实处置优先于鱼获和奇观。
- 不使用V1系统、任务、奖励、关卡界面和固定入梦。

## 伪纪录片写法

伪纪录片只提供三种质感：

1. 现场记录可能不完整。
2. 人物当时的判断与回放结果可能不同。
3. 拍摄行为会带来取舍、争议和关系压力。

摄制人员必须逐步成为有关系、有立场的人，不能长期以“摄像师”充当功能问答器。人物尚未确认姓名时，减少其对白占比，用具体动作和现场分工表现存在。

## 情绪基线

档案001推荐递进：

`熬夜空军的无聊 → 被拍摄后的嘴硬 → 正常诊断失效的纳闷 → 小黄与水面异常带来的不安 → 受力判断后的专注 → 听见老莽头的慌乱压制 → 是否强拉的犹豫 → 主动卸力后的失落与余波`

不要求逐项打卡，但不允许从嘴硬直接跳到正确判断，也不允许异常一出现就进入专业结论。

## 章节规模

第一卷正文优先参考V1单章约1800至2800字的容量。容量用于容纳生活、关系、判断和情绪，不用于注水。

档案001的四章应各自拥有完整小弧线，同时形成一条连续夜钓经历。不能把“冷开场、诊断、发现旧线、主动卸力”写成四段加长分镜。

## 专属禁用倾向

- 连续使用“浮漂没动。线动了。”“不是飘。是绷。”式短句。
- 让摄像师连续问“这是什么”“拍到了吗”“为什么”。
- 由旁白解释证据等级、受力意义、生态价值和主题。
- 用“严格来说”“这点很重要”“两种情况都不能”替人物思考。
- 用“更深处的一片黑水”“真正的调查才开始”作万能结尾。
- 把旧线、鳞片、血迹和水纹写成依次打卡的触发清单。

## 交付判断

正文完成后必须能回答：

- 删除摄像机后，这一章的人物经历是否仍成立？
- 删除所有设定名词后，读者是否仍能感到异常？
- 老姚的选择是否先是人的选择，再是主题表达？
- 读者能否记住至少三个具体现场物件和一次情绪转折？
- 这一章是否像小说，而不是故事基底、短剧脚本或Seedance提示词？
