# novel-bible-manager 测试说明

本 skill 的测试重点是资料分层和写入安全。

检查项：

- 目标小说缺失时不写入。
- 已确认设定、待确认设定、灵感草稿、外部参考能被区分。
- “可能、也许、暂定、灵感、参考”不得进入 `已确认设定.md`。
- 与已确认设定冲突时先提示冲突，不覆盖。
- 角色、地点、势力、术语能进入正确资料文件。
- 外部资料未确认前不得进入正式设定。
- 输出本次整理报告和待确认问题。

当前限制：

- 本轮未使用子代理做基线对照，因为当前工具要求用户明确授权后才能派生子代理。
- 已保留测试场景，后续如需要正式评估，可按 `evals/evals.json` 执行 with-skill / without-skill 对比。
